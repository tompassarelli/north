North — fleet session console

Usage: north [COMMAND]

Run north with no arguments to open the fleet screen.

Commands:
  wisp payoff [--since YYYY-MM-DD] [--json]      Measure Wisp agreement and native utilization
  health [--dry-run]                             Check harness invariants
  citation-check [--root DIR] [--list]          Fail on a doc, skill or hook that cites a north subcommand the CLI does not define
  review-items PLAN [--author TIER] [--root DIR]  Split a design review into fact, scenario and architecture items, run the facts, route the rest by tier
  ci-diagnose [--dry-run OWNER/REPO RUN_ID]      Comment a Haiku-extracted, Opus-judged diagnosis once per failed run on each open "main is red" issue
  red-main-notify                               Tell each open "main is red" issue's culprit lane session and the proxy, once per culprit commit
  main-red RUN_ID                               Confirm a failed main CI run once, then ask the lander to revert its culprit (GH_REPO names the repository)
  language-gate --repo DIR --base REV --head REV  Check language policy
  code-health crate-lines [--repo DIR] [BASE HEAD]  Print non-test Rust lines per workspace crate against structure.toml [crate_lines]; with BASE HEAD exit 1 when a crate over its cap grew
  code-health imports                           Resolve the imports of files given as JSON on stdin
  code-health report|gate|check|signal|review-done [--repo DIR] [--config FILE] [--rev REV] [--json]  Measure structure.toml debt: full report, new debt between two commits, one dirty file, the recurring-review signal, record a review
  code-health habits [--repo DIR]               Run the Rust habit checks
  code-health build-time --repo DIR [--workspace REL [--leaf REL --hub REL]] [--samples N] [--ledger FILE] [--rev REF] [--file]  Time cold and one-line-edit cargo build and test --no-run, append to the build-time ledger, exit 1 over the structure.toml threshold; --rev measures a fresh detached checkout of REF, --file keeps one rolling split issue per repo
  guard language                                PreToolUse language guard
  grounding [refresh|query|hook|distill|score]    Retrieve existing infrastructure and history
  work [list|search|show|claim|release|need|unneed|close]  Work items
  agents [status|stale|inspect|path|on|off|sync|busy|plan|usage|presence|routines]  Run the agent catalog, plan, usage and routines commands
  config agents [sync|status|on|off|path|inspect|check-hook-paths|check-owners|live-refs]  Manage skills and hooks
  config check [--package DIR]                 Check the agent-machinery package: catalog shape, units, assets, schemas, contracts and its portable source boundary
  config check guides [--refresh] [--guides DIR]  List the vendored agent-policy guides and fail when one is over 90 days old; --refresh re-fetches them at their upstream head
  session-host --name N --generation G --state-dir D -- ARGV  Host one headless runtime
  dep-gate BASE HEAD                            Check dependency changes before landing
  denylist scan (--config FILE | --south DIR) BASE HEAD [--ref NAME]  Scan an outgoing range, its messages, ref name and arriving files for deny-listed terms
  denylist attest --south DIR --repo OWNER/NAME [--repo ...] [--branch claude/X]  Post the denylist status on claude/ tips and dispatch Autoland when clean
  autoland-status --sha SHA --branch BRANCH      Read this lane's Autoland result
  autoland-wait --sha SHA --branch BRANCH --destination BRANCH  Wait for its landed result
  land-abandon [BRANCH | --superseded BRANCH]    Delete a superseded or handed-back branch from origin
  land serve [--once] [--repo DIR] [--checker PROGRAM]  Land the queued lanes of this origin: one candidate, checked once by safe-push --check-candidate, pushed to main by lease
  land promote [--dry-run] [--shadow-minutes N] [--repo DIR]  Replay recorded rounds and shadow the queue with the current runtime, then point the lander link at it
  land withdraw TICKET --reason TEXT [--repo DIR]  Move a queued ticket out of the landing queue, tell its session why and record the incident
  land scan dep-gate|tool-removal|test-integrity BASE..HEAD  Run one landing scan on an outgoing range: the dependency gate, a removed bin tool, or an added mutation marker or test skip
  land scan denylist|commit-email|native-ref|secrets|publication ARGS  Run one outgoing-change scan: the private-value deny-list, author and committer emails, native item references, gitleaks, or all publication scans
  land-clean LANE_ROOT | --sweep                 Remove a lane's cargo target after its land checks, or trim the shared cargo targets under 10 GB
  land-train record|check|red ...                Record a train verdict, a check run or a red-main interval in the threads ledger (north flow shows the tempo)
  incident record|guard|import|report ...        Record a failure the moment it happens, the guard that closes its class, or read incidents by class, detector-first rate and recurrences (north flow prints the week)
  landed-tree [--repo DIR] BASE TIP              Exit 0 when TIP's changes are already on BASE by tree or superseded by later commits to the same lines
  stale-revert [--repo DIR] [--lane TIP] BASE HEAD  Refuse a landing whose diff from BASE removes lines that recent BASE commits outside the lane added
  lane-squash [--repo DIR] [--message FILE] DEST_TIP  Fold the lane's unpublished commits (none on origin) into one commit with their trailers merged, for safe-push --to main
  merge-driver set [--config FILE] BASE OURS THEIRS PATH  Git merge driver: merge the order-insensitive unique-entry lists named in harness/merge-sets.toml, refusing duplicates and remove-versus-edit; leave its regenerated files conflicted
  merge-driver continue [--config FILE]         Finish a rebase or cherry-pick stopped only on regenerated files: run each generator on the merged sources, stage and continue
  bin-references --repo DIR --base REV --head REV [--nixos-config DIR] [--south DIR]  Refuse a landing that deletes a bin/ entry or removes a north subcommand or flag a deployed nixos-config or south unit, or this host's user units, still run
  land-tests [--jobs N] [--cases json] TEST...                  Run land-check tests (shell, Python or built test binaries) side by side, reporting every failure
  land-cache key|hit|record --repo DIR --head REV --command CMD [--status N]  Reuse a passing land check whose inputs (command, filtered path trees, south and nixos-config HEADs) are unchanged
  land-actions --workflow FILE --base B --head H --timeout S -- COMMAND...
                                                 Run land checks as a GitHub Actions workflow on a scratch branch and wait for its verdict
  safe-push [--dry-run] --tag NAME               Scan and publish one annotated tag (branches still land through bin/safe-push)
  safe-push-result STATUS SHA REASON MINUTES URL  Print safe-push.s terminal result
  nix explain <nix subcommand | class>           Print a Nix footgun card, then the option sections of this host's `nix <cmd> --help` it names
  nix gc [--dry-run] [--max-freed SIZE]          Root every promoted runtime, live worktree dev shell and rustup wrapper store path, then collect the store
  doctor nix [--lock FILE [--allow FILE]]        Report each dev shell as rooted and enterable offline, missing rustup wrapper store paths and a second nixpkgs in flake.lock
  contract-probe --validate FIXTURE | --runtime PATH  Check the claude stream contract
  provenance [check|debt|audit]                  Audit grounding and target debt
  brief new --category CATEGORY                   Print a worker brief skeleton carrying every line the brief guard requires for that category
  proxy calls TRANSCRIPT                         Count a Claude Code transcript's main-thread tool calls by kind, with streaks between hand-offs and shapes run 20 or more times
  issue-box-lint [REPO#N...] [--repo REPO]       Check issue acceptance boxes
  agent-config-check [--local] [--policy-only] [--verbose]  Check the shared agent harness, Codex wiring, routines, skill budgets, rules register and vocabulary
  agent-config-check policy-gate (budget|measure|session) [--repo FIRN] [--operator DIR]  Run only the skill budget or the startup-token regression gate agents sync uses
  agent-config-check tree-policy [--tree DIR]  Check one north tree's skills against the byte and playbook limits with no other checkout or live state; the land check for harness/ and agent-machinery/
  agent-policy-contract --repo FIRN [--north DIR] [--local] [--write] [--codex-adapters]  Check policy surface ownership and generate or verify provider hook wiring
  mutant record ID | verify BASE HEAD           Record a scratch-copy mutant, or run each Test-kind kill claim once under one lease
  archives REPO NUMBER                           Print the archive tags whose commits reference REPO#NUMBER, with restore commands
  threads ARGV                                  Run a NorthThreads command on the ledger host
  remote-serve --peer HOST [--repos REPO,...] [--log FILE]  The ssh forced command for a peer key: run SSH_ORIGINAL_COMMAND only if the allowlist and the peer's guards admit it, exit 126 on a refusal, and log one row per call
  remote-serve audit --peer HOST [--log FILE] [--keys FILE]  Count a peer's logged calls and refusals and print its key's days to expiry-time from authorized_keys
  cloud [list|events|sweep|send|wait|collect|land|reap|launch]  Launch, read, message, wait on, land, reap and sweep Anthropic cloud sessions
  dispatch [--dry-run]                          Launch ready makgora and wisp boxes on every free worker slot
  tune [--dry-run]                              Daily learning tick: write the ledger-decided routing, ETA and budget cells and file cost rises
  ops dividend [--dry-run] [CHECK]              Evaluate each bet issue's dividend over 7 days, comment PAYING or DECAYED daily and message the proxy on DECAYED
  ops check [--dry-run]                         Run the core expectations from north-data/expectations.toml, alert once per breach and once per clear, and leave a heartbeat
  incident-mine [--days N] [--chunks N] [--per-thread N] [--out DIR]  Mine transcript incident candidates through convo into classifier chunks
  defaults-measure DB KIND | --priors DB | DB --propose --train-until DATE --json  Sweep a measured default walk-forward over the ledger, count prior settling data, or propose read-only defaults
  context audit [--since 7d] [--json] [--session ID]  Measure injected context per session by source: startup, skills, references, grounding, other hooks
  worker-ledger [--session ID] [--since DATE] [--backfill] | --summary [--by LIST] | --recommend FACETS  Record finished workers as runs, summarize them per cell and tier, or recommend a tier
  policy-replay promote SCENARIO.json... [--candidate PATH] [--operating-point PATH] [--accept-drop REASON]  Copy a sweep candidate into the operating point, refusing a missed scenario, a flip or a drop
  fleet [list|launch|send|ask|show|stop|forget]  Run headless agent sessions; no argument opens the screen
  private-desktop [start|control|capture|type]   Run or control an isolated private desktop
  ledger [runs|summary] [--json]                Fleet turn records, cost and task verdicts
  orders [list|add TEXT...]                     Tom's standing orders, rendered into every fleet launch and revive
  task [landed REF SHA | check REF -- CMD... | check [--dry-run] (--body-file FILE | REPO#N | --repo R)]   Record a verdict north observed itself, or tick issue boxes whose Observe: command exits 0
  tempo [--repo NAME] [--window MINUTES] [--json] [--record]   How fast lanes reach main through the lander: landed, queued->main and first commit->main p50 and p90, refused alone, queued now; --record writes the last hour and day to the ledger (hourly timer)
  gate [open --session S --question Q --option O... --recommend N --default N --default-after D [--issue OWNER/REPO#N] | answer ID N [--note TEXT] | list [--json]]  Open or answer a decision gate
  digest [--since DURATION]  Print what landed, what is in flight, open gates with their recommendation and stalls from the fleet store
  follows-release [--repo-dir DIR]             Start queued boxes after predecessors land
  dev-shell run [--dir D] (--prepare | -- COMMAND...)  Run COMMAND inside the flake default dev shell, entering it once offline from its GC root; --prepare realises the root
  capacity admission < FACTS.json               Decide one machine-capacity admission
  capacity laptop-auto [--dry-run]              Stop agent game load while Tom's declared gaming hold is on, reap orphaned scopes
  capacity seat-idle-hint [--seconds N]         Set logind IdleHint from Wayland input idle, which ignores idle inhibitors
  capacity mode status|tick|hold [--minutes N]|extend|release  Show or set the laptop mode (away, desktop, play) and why; hold starts or extends a playtest lease
  capacity gaming on|off|status                 Set or release a play hold, which expires by itself
  capacity game-reserve on [--auto]|off|playing|status Reserve CPUs for Tom's game (Warcraft III or a Wisp native window), moving Warcraft III only once it has run 60 s; the playtest lease (capacity mode hold) turns it on and off
  capacity offload choose | run --host H --base B --head S --timeout N -- CMD  Run a held land check on another host with room, shipped by git bundle
  capacity watchdog step < SAMPLE.json | replay SAMPLES.jsonl  On sustained host overload name the top process trees by fleet session, cap the offending session scope and tell its owner and coordinators
  nexus-ram record                              Append one Nexus memory, CPU steal and pressure row (minutely timer)
  nexus-ram report [--days N]                   Judge Nexus RAM headroom: UPGRADE or STAY, steal minutes and longest row gap
  laptop open|close|drain|toggle|status|tick|observe  Set or read the laptop's placement availability on the ledger host
  laptop-runner                                 Take and run queued laptop and pool jobs while the laptop is available (timer)
  laptop-ntfy serve|notify|press open|close     Phone signals for the laptop state: button endpoint, daily window reminder
  agent-contain sweep [--dry-run]               Move agent children out of Tom's slices into agent-capacity.slice and freeze stray containers
  watch --once                                  Run every work probe once (capacity queue and pressure, workers, waits, runtime-follow, host reachability) and print one line per alert
  job-watch run [--registry DIR] [--peers FILE] [--state FILE] [--dry-run]  Alert once when a registered scheduled job is overdue, and when it recovers
  model-watch [--alerts-only] [--topic T] [--sources FILE]  Snapshot public model, release and market sources, rank new candidates once on the plan, send the digest; --alerts-only sends location warnings
  model-watch news [--days N] [--noise ID|--more ID]  Show the last delivered watch digest or record feedback on an item
  outside-watch run [--dry-run] [--days N]       Minimize and block promotional spam on Tom's GitHub repos, report real outside people to the proxy inbox, mark our own notifications read
  outside-watch status                          Show the last run and its log line
  reclaim [--dry-run] [--idle-hours H]          Remove /tmp scratch and Wisp LAN pair copies idle 24 h, cargo targets of north main and of every repository's worktrees and lane-private cargo-target-* caches idle 4 h, all held by no process or pool, and trim the shared cargo target to 10 GB (hourly timer)
  retain [--dry-run] [--host H] [--archive DIR]  Archive gex45 Mak'gora evidence and capture batches past their retention age to the laptop, sha256 verified, then delete the gex45 copy; a PINNED file or an open process keeps an entry
  worktree-layout-check                         List worktrees outside ~/code/<project>/main, worktrees/<slug> and pins/<full-object-id>
  hardcoded-repo-path-check [--write-allow]     Count hard-coded repository paths against config/hardcoded-repo-paths.tsv
  docs features-index [--check] [--root DIR]    Regenerate docs/features.md from the one-file-per-feature tree under docs/features/, or with --check fail when it is stale
  docs rationale-index [--check] [--root DIR]   Regenerate docs/rationale/README.md, one line per note: title, link, first sentence; --check fails when it is stale
  lane-gc [--remote] [--dry-run] [--repo NAME]... | --unlanded  Retire landed, superseded and stale lanes and origin branches behind verified archives; report unlanded work (hourly and daily timers)
  pin-retire [--dry-run] (--consumer-main PATH... | --unconsumed) -- PIN  Retire one verified-unused content-addressed pin and its sidecar
  wt-reap [--all] [--dry-run]                   Remove spent lanes: clean, two hours old, merged into main or patch-equivalent to it
  wt-rescue [path] [--dry-run]                  Move a dirty main checkout's changes into a new rescue lane and clean main
  usage-web-read                                Read the Claude reset counts from the automation browser into the usage cache (6 h timer)
  runtime update                                Promote origin/main as this host's north runtime with its own tree
  supply-chain-scan                             Scan origin/main lockfiles with osv-scanner and alert on new advisories (daily timer)
  incident-retro [--dry-run]                    Mine the last 7 days with incident-mine, sample every fifth candidate and launch one Haiku session that appends the kept rows to south agents/incidents.jsonl and files each recurring mode with no enforcer as a rules.toml [[candidate]] (weekly timer)
  watch-review [--dry-run]                      Launch one fleet review session per due followed source in south agents/watch.toml (30 days since the last review with new commits, or 10 new commits), tell the proxy when a launch fails or is held (daily timer)
  codex-runtime-gcroots                         Root the Nix store dependencies of every installed Codex runtime
