North — fleet session console

Usage: north [COMMAND]

Run north with no arguments to open the fleet screen.

Operator console:
  glance                One line: anything broken, the money, and what waits on Tom
  dash                  The board: landings and boxes per hour, then four concern panels
  fleet                 Sessions, dispatch, pace, usage, laptop, orders, digest, report
  gate                  Open, answer or list decision gates
  ledger                Fleet runs and cost; worker tiers, flow, tempo and incidents
  task                  Record a verdict, or tick boxes whose check passes
  cloud                 Launch, message, land and reap cloud sessions
  desktop               Run a private desktop or take a screenshot off the clipboard
  convo                 Search and read past agent transcripts

Work and knowledge:
  work                  The fleet's work, gates, landings and lane flow; work items
  graph                 Record and query facts, ground prompts, list the ready backlog

Engineering and landing:
  check                 Citations, concerns, boxes, nix, provenance, privacy, the harness
  safe-push             Check and land a lane, or publish a tag
  land                  Serve the landing queue, run its checks, abandon or release
  lane                  Collect, reap, rescue, seed, squash and audit lanes
  code-health           Structure debt, crate lines, build time; split modules out
  test                  Coverage map and mutation sweeps
  docs                  Regenerate or check the docs indexes
  nix                   Explain a Nix footgun, or root and collect the store
  operator              Paths north reads from the operator repository, each with its class

System and telemetry:
  accounts              Each account's state, 5h and week room, and each api grant's dollars
  health                Readiness bars, concerns and harness invariants
  infra                 Live paid resources with their monthly price and a total
  config                Skills and hooks, agent plan and usage, context, proxy calls
  runtime               Update, deploy or check the north and agent runtimes
  capacity              Leases, modes and watchdog; bounded, nexus and dev-shell runs
  ops                   Watch, expectations, credentials, GitHub, strategy, news
  help                  Show this help

Run north COMMAND --help for its usage and contract. Run north --help-all
for every command, including those run by timers, hooks and programs.

Options:
  -h, --help  Show this help
      --help-all  Show every command with its contract
