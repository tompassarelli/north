North — every command, including those run by timers, hooks and other programs

Usage: north [COMMAND]

Run north --help for the operator and agent commands, or north COMMAND --help for one.

Commands:

  accounts reset [--dry-run]                     Check the coordinator's usage reset grant against its Fable meter and log the outcome to ~/.local/state/north/usage/resets.jsonl; it never clicks the reset (docs/rationale/usage-resets.md)
