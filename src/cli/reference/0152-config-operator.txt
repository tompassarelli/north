  config operator paths [--class CLASS]         One line per path north reads from the operator repository, as PATH<TAB>CLASS in the inventory's order; class is schema, generic method, private value or secret
  config operator check [DIR] [--only NAME,...] [--distinct-from OWNER]  Read the operator repository's schema-class files against their typed keys; each finding prints as FILE: KEY: reason and the command exits 1; with --distinct-from a string a template DIR holds at an identifying key (id, name, email, repo, path, host, source and the like) that equals the owner repository OWNER's string at that key is also a finding naming the file and key, never the value; DIR defaults to the resolved operator root, NAME is costs, claude-accounts, credentials or infra
  config operator init [--check] DIR                    Create the operator repository DIR (which must not exist or be empty) holding synthetic values for every file north reads from it (accounts, costs, credentials, policy lists, orchestration, privacy lists, infra, a secrets note, the schema marker and a landing configuration) and a catalog registering each skill of north's structure registry; `north config operator check DIR` passes on it; init --check DIR exits 1 naming each file of DIR that differs from, lacks or adds to that output
