- Host token push: `north ops github push-token --host HOST...` copies the short-lived push token and the list of repositories it covers to each named build host over the existing ssh route, and tries a host whose copy failed again every 10 seconds, with a freshly asked token, until it succeeds or 27 minutes have passed since the start, so a short network drop no longer leaves a host with a stale token until the next scheduled copy. Hosts already copied are not copied again, one stderr line per failed attempt names the host and the reason, and the verb exits 1 while a host has no fresh token (north#1175).
