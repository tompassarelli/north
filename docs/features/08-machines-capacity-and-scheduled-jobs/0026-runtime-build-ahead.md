- Runtime build ahead: when `north land serve` builds a north candidate that changes a runtime input, it asks for that candidate tree's release north through `north runtime build-ahead --tree TREE --commit COMMIT` while the candidate's checks run. The request runs in its own transient unit under a runtime capacity lease, one at a time, and keeps the two runtime programs under `${XDG_STATE_HOME:-$HOME/.local/state}/north/runtime-artifacts/TREE`, never for a tree an artifact already covers. The promotion of the landed commit carrying that tree installs the artifact instead of reusing or building, and journals `artifact-ready` with 0 s in `runtime-pins.jsonl`; a landing whose tree differs (a rebased or bisected candidate) builds as before (north#1022).
