- Runtime promotion: every host runs origin/main's north within minutes of a landing, and rolls back on its own when the new runtime cannot run a land check. After a north landing safe-push runs `north runtime follow`, and each host's `north-runtime-follow` timer runs `north runtime update`, which pulls or builds the runtime (a build in progress always finishes), swaps `current`, and swaps back with an alert to the proxy only when `north runtime health` fails; a failing `agents sync` keeps the runtime, alerts once per cause and retries each tick (north#731). On the host that settles the fleet, `north runtime settle` ships to the other hosts in parallel, runs one canary land check per promoted SHA per host (rolling back where it fails), and logs each host's swap time per landing to `runtime-live.jsonl` for the scoreboard's landing-to-live bar. Deploy and settle move a host forward only (north#651). A host set `publishes_host_facts = false` has its config facts published by the settling host (north#653). See `north runtime --help`.
