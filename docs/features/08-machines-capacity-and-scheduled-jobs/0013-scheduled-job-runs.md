- Scheduled job runs: `north job-run [--path DIRS] [--user USER] [--class CLASS] [--notify] NAME -- CMD...` wraps a timer's command (with `--class moderate|heavy|gpu`, or when it compiles Rust, as a capacity lease held to its leased CPUs), records its start and finish through `threads job-run` and exits with the command's code; with `--notify` it detaches the command and sends `job-run: NAME exited RC` to the fleet session when it ends. The record holds name, host, started, finished and rc, spooled while the remote ledger is unreachable. `--notify` runs the command in its own session with its output in `~/.local/state/north/jobs/`, returns at once and sends the message to the fleet session `$NORTH_FLEET_SESSION` (the session host reads the job's JOB-START lease with `north fleet row leased SESSION` to know a quiet child waits on it, and the old shell `job-run` wrote no `.job` record), so an agent ends its turn and wakes on the result, and the job outlives a subagent's teardown. `threads job-runs` shows runs, failures and the last rc per name and host. Firn's `jobRun` helper wraps every registry timer.
