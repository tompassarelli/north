- Scheduled job runs: `north job-run [--path DIRS] [--user USER] [--notify] NAME -- CMD...` wraps a timer's command, records its start and finish (name, host, started, finished, rc) through `threads job-run` (spooled while the remote ledger is unreachable) and exits with the command's code; `--notify` instead detaches the command into its own session with its output in `~/.local/state/north/jobs/`, returns at once and sends `job-run: NAME exited RC` to the fleet session `$NORTH_FLEET_SESSION` when it ends (the session host reads the job's JOB-START lease with `north fleet row leased SESSION` to know a quiet child waits on it, and `bin/job-run` writes no `.job` record), so an agent ends its turn and wakes on the result, and the job outlives a subagent's teardown; `threads job-runs` shows runs, failures and the last rc per name and host. Firn's `jobRun` helper wraps every registry timer.
