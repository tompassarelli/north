- Scheduled job runs: `north job-run [--path DIRS] [--user USER] [--class CLASS] [--scratch ROOT] NAME -- CMD...` wraps a timer's command (with `--class moderate|heavy|gpu`, or when it compiles Rust, as a capacity lease held to its leased CPUs) and exits with the command's code; with `--scratch ROOT`, which the host configuration sets for its fleet units, the command gets the fresh directory `ROOT/NAME` as its `TMPDIR`, emptied first of whatever a killed run of the same job left and removed when the command ends, so on the laptop every scheduled north job keeps its scratch in memory (north#1553). `--path` and `--user` are accepted and unused since the job ledger and the fleet notify they served went (north#1650). Firn's `jobRun` helper wraps every registry timer.
