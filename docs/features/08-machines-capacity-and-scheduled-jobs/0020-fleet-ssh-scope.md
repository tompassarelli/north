- Fleet ssh scope: `bin/ssh` is a PATH shim that sends a fleet session's ssh through `north ssh-session`, which runs a remote command on the far host inside the user scope `north-ssh-SESSION-XXXXXXXX.scope` (unscoped when that host has no user bus or `systemd-run`), so the far host's capacity watchdog lists the session behind the load instead of "no fleet session (ssh)" and caps that scope rather than a smaller fleet unit. Logins, `-N`, `-O`, git transport and the `north`, `threads` and nix protocol commands a peer's forced-command key parses pass through unchanged. When the largest offender is attributed to a session but is no unit the watchdog may cap, it caps nothing and tells that session (north#626).
