- Credentials registry: `north credentials check [--json]` lists every credential the fleet uses: south's sops files (each declared in south `agents/credentials.toml`; an undeclared file fails), the Claude setup-token files and `.credentials.json` logins that `agents/orchestration.toml` places on this host, and the declared sites of the automation-chrome cookie store. Each row shows kind (`machine` or `human-session`), a fingerprint, expiry and renewal path, never a secret value. It exits 1 on any human-session, expired or undeclared credential and marks a refresh token held by two logins as a copy. `north credentials renew [--dry-run]` is the daily closed loop `credentials`: it runs the declared renewal command of each machine credential within `credential_expiry_notice_days` (30) of expiry, sends what needs Tom as one nexus-alert notice (again after a week or a change), and writes `north/credentials/check.json`. It never copies a credentials file between hosts. See docs/rationale/credentials-registry.md.
