- Admission ledger rows: each capacity admission that ends in a lease, a deferral or a refusal (`north capacity host run` and `reserve`) is kept in the host's capacity.db with its owner, class, reason, queued seconds and the cpus and memory it asked for, and the next `north ledger worker` run on that host ships the ones the ledger lacks as `capacity` rows into the threads ledger's `capacity_admissions` table (north#798). A host ships only what is at or after its newest recorded admission, `north threads run-ids --capacity` names that time per host, and a repeat adds no row. `bin/subsystem-ledger` counts these rows as the decisions of north-capacity. A host keeps an admission for 35 days.
