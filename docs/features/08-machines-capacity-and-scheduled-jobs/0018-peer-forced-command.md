- Peer forced command: a peer host's ssh key runs `north remote-serve --peer HOST [--repos REPO,...]` as its forced command, which lexes `SSH_ORIGINAL_COMMAND` without a shell, refuses shell metacharacters and `env` assignments, and admits only allowlisted peer verbs (`readlink .local/state/north/current`, `north runtime health`, `north holds list --here --json` and `south land`, narrowed on a worker host for the ledger peer to `readlink .local/state/north/current` and `north runtime health`). A refusal exits 126; every call, admitted or refused, appends one row (verb, refusal, exit, milliseconds) to `~/.local/state/north/remote-serve/HOST.jsonl`. `north remote-serve audit --peer HOST` counts the calls, refusals and failures in that log and prints the key's days to its `expiry-time` in `~/.ssh/authorized_keys`.
