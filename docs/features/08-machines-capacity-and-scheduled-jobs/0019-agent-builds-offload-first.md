- Agent builds offload first: a heavy build in a fleet session (`NORTH_FLEET_SCOPE` set) is offered to the `[hosts.NAME]` build hosts before the laptop decides on it and runs on the first with room, while the laptop does not lease its own builds (attended); it stays for local admission only when no host has room or none is configured. A host that leases its own builds (the laptop while away, filling to 22 of its 24 threads) decides on the build first and offers it to a build host only when its admission defers it (north#740). Builds outside a fleet session, landing checks and pinned work keep their classes. `heavy-command-guard` finds `cargo`, `tsc` and `bun` behind launchers such as `bwrap`, `systemd-run` and `xargs`, and refuses to route a build whose command also writes files or the git index (north#259, north#674). A fleet session's Rust compile (`cargo`, `rustc FILE.rs`, `cargo-nextest`) is found through depbox, `nix develop -c` and `bash -c`, and on a host that does not lease its own builds runs on a build host or is refused with the hosts' reasons, never compiled locally; each Cargo.lock the offloaded run changed is written back into the lane. `north land enqueue` runs its checks before queueing on a build host when `.safe-push` names `runner = build-host`, and when none has room it runs them on the queueing host under the land-check capacity lease; a failure or no verdict refuses the lane (north#671, north#697).
