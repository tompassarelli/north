- Resource model: every finished capacity run records its command key, host, cache state, queue wait, memory peak and stall, whether its memory cap censored it, and what admission predicted. Finished runs feed a per-host model at four levels (exact command and cache state, exact command, owner and shape, shape on its host); a failed or timed-out run teaches only its duration, as a lower bound the model's Kaplan-Meier percentiles honor, and admission sizes a command's memory from the answering level once it has enough runs (`capacity_memory_margin`); a key with no level reports `unknown` instead of borrowing a wider estimate, and a censored run only raises the key's memory floor. `north capacity model [KEY]` prints the levels and `north capacity calibration` prints predicted against actual wall time and memory per key and host, flagging drift, and the share of admitted runs that carried a prediction. A key flagged drift on its newest predicted runs widens its next prediction with no edit: wall time moves from p50/p90 to p90/max and memory by `DRIFT_MEMORY_WIDEN`.
