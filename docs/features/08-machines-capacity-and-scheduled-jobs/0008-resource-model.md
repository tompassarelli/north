- Resource record: every finished capacity run appends its command key, host, cache state, working directory, queue wait, CPU, memory peak and stall, disk reads and writes, and whether its memory cap censored it, to the host's usage log. Admission sizes a command from that log's newest runs (`capacity_memory_margin`), `north capacity host estimate` prints the estimate its closest runs give, and a censored run raises the next charge of its command to 1.5 times the cap it hit.
