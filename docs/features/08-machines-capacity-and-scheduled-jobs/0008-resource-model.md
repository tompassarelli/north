- Resource model: every finished capacity run records, in one SQLite transaction, its command key (owner prefix and shape), host, cache state (warm when the lane's Cargo target held fingerprints before the run), queue wait, sampled anon peak (`memory.stat` anon plus shmem), memory stall (`memory.pressure` some total), whether it was censored (over 1 s of stall within 10% of its MemoryHigh) and what admission predicted; successful runs update a model holding the newest 20 wall seconds, CPU-seconds and uncensored anon peaks per level, all keyed to the recording host: exact command × cache, exact command, then owner and shape (3 runs per level); a key with no such level reports `unknown` rather than borrowing a wider estimate, and the older `estimate` and declared-class sizing read only this host's rows. A censored run is a lower bound: it adds no memory point and raises the key's floor to 1.5x its cap. Once the answering level has 5 runs admission sizes MemoryHigh and its memory check from the larger of its p90 anon times the memory margin and that floor. `north capacity model [KEY]` prints each level; `north capacity calibration [--since 24h]` prints per key and host the predicted against actual wall and anon peak, error p50/p90, p90 coverage and DRIFT when a p90 error passes 50% or coverage falls under 80%.
