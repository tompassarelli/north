- GitHub mirror: `north github-mirror sync [--repo NAME]...` keeps north's, makgora's and wisp's open issues, main CI runs and main check results in `~/.local/state/north/github-mirror.db` (`NORTH_GITHUB_MIRROR` overrides). Each read sends the ETag it holds, so an unchanged repository costs only 304 answers, which do not count against the rate limit. Open issues are fetched again over GraphQL only when the newest-updated-issue probe changes or the copy is 30 minutes old. `north dispatch` reads open issues and their blockers' states from the copy while it is under 5 minutes old, and reads GitHub only when it is older, with a note saying so.
