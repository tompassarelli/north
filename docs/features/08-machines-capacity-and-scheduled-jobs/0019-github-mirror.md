- GitHub mirror: `north github-mirror sync [--repo NAME]...` keeps north's, makgora's, wisp's and firn's open and closed issue numbers, branch tips (probed by a matching-refs read), tags, releases, main CI runs and main check results in `~/.local/state/north/github-mirror.db` (`NORTH_GITHUB_MIRROR` overrides). Each read sends the ETag it holds, so an unchanged repository costs only 304 answers, which do not count against the rate limit. Open issues are fetched again over GraphQL only when the newest-updated-issue probe changes or the copy is 30 minutes old. `north fleet dispatch` reads open issues and their blockers' states from the copy while it is under 5 minutes old, and reads GitHub only when it is older, with a note saying so. The CI watch (`north ci-diagnose`, `north red-main-notify`), `north lane gc --remote` branch tips and `repo audit` branches, tags, releases and issue states read the same copy under the same 5-minute rule and call GitHub only on a miss. It also keeps each Pages source, the repository list and each branch's commits ahead of main (batched GraphQL compares, only for changed tips), so a fresh copy leaves `repo audit` no GitHub call. A host with no GitHub reader of its own reads the ledger host's copy instead: `north github-mirror serve` (a remote-serve verb) writes a consistent copy to stdout, and `north github-mirror pull DEST` replaces the host's mirror whole with the copy DEST serves, as gex45 does from nexus (north#1054).
