- Landing watch: safe-push appends one JSON line (`time`, `repo`, `lane`, `sha`, `stage`, `status` start|end|wait|retry|failed|refused|landed, `detail`, `seconds`, `pid`, `session`, `host`) to `~/.local/state/safe-push/events.jsonl` at each stage end, known wait (lock queue, landing train, pre-push and land checks, scans, Autoland), retry, land-check or push failure, refusal and landing, and on any failure or refusal starts `north watch --once` at once; the `north-watch` user timer (nixos-config `modules/north-watch`, beside `north-runtime-follow`) runs it every 30 s too. Each pass reads those events, `stages.tsv`, the queue tickets, live safe-push processes, `runtime-settle.json`, one `gh api repos/R/actions/runs?per_page=40` per repository (north, south, nixos-config, makgora, wisp; `NORTH_WATCH_REPOS` overrides) and the `claude/land-*` branches of Autoland repositories, and alerts on: main CI failed on a main commit (naming lanes whose land checks failed in the last hour); two lanes' land checks failing the same test within an hour ("possible red main"); a live landing with no event for 120 s outside a known wait; a check running past its p90 + 50%; an Actions run queued over 120 s; a GitHub push rejection or API error; a queue with no landing for longer than queue length x the p50 landing time (at least 10 min); a lane re-queued more than twice; an Autoland run failing or `claude/land-*` branches waiting with no Autoland run for 10 min; the runtime not live and healthy after a landing (`north runtime settle`). Probes are `fn(&WatchContext) -> Vec<Alert>` in `crates/north-landing/src/watch/` listed in `PROBES`: they read only the context gathered by `facts::gather` (add a field and its reader there for a new source), and an `Alert` is `{ key, severity: Info|Warn|Page, repo, owner, summary, since }` with a key stable per incident (`land:REPO:stall:LANE`); a probe whose source failed pushes its key prefix into `unavailable` so its incidents are kept, not cleared. The one sink (`watch/sink.rs`, state `~/.local/state/north/watch/incidents.json`) sends a new Warn or Page alert once by `north fleet send` to the proxy and the owner's lead, repeats it every 10 min while it lasts, sends `north watch: cleared after N min: ...` when it ends, and raises one `notify-send` for a Page alert 5 min old. Each pass writes `~/.local/state/north/watch/heartbeat`, and `north flow` prints `landing watch: silent` when it is older than 2 min.
