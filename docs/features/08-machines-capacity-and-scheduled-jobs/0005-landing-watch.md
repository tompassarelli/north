- Landing watch: safe-push appends one JSON line per stage end, known wait, retry, failure, refusal and landing to `~/.local/state/safe-push/events.jsonl` and starts `north watch --once` on any failure or refusal; the `north-watch` user timer runs it too. Each pass gathers those events, the queue, live safe-push processes, runtime settle results and GitHub Actions runs, and the probes listed in `PROBES` (`crates/north-landing/src/watch/mod.rs`) raise alerts on landing and CI trouble. `crates/north-landing/src/watch/sink.rs` sends each new incident once to the proxy and the owner's lead, repeats it while it lasts and says when it clears; `north flow` prints `landing watch: silent` when the watch heartbeat goes stale.
