- Capacity estimates: `machine-capacity estimate [--json] [--class CLASS] [--owner OWNER] -- CMD ARG...` uses the current directory and the last 20 matching measured runs, with exact signature, full owner/shape, owner prefix/shape/class, family/repo, family (none for unrecognized `other` commands), and declared-class fallbacks. An expensive target absent from exact family/repo/package history stays heavy (native for native clients) with low confidence, even when other targets have family history; known targets and cheap families retain nearest matching. Imported rows without exact targets cannot establish that a target is known. Owner levels require an explicit owner; the prefix is its leading ASCII letters. It prints p50/p90 cores, peak memory, I/O bytes, disk busy share, sample count, match level, and confidence. Disk busy share is the maximum physical whole-disk `/proc/diskstats` I/O-millisecond delta divided by run wall milliseconds (host-wide; partitions and virtual devices excluded). Stored cgroup I/O pressure is reference data only. Runs without a class reserve rounded-up p90 cores and p90 memory plus 20%; running batch CPU accounting uses the greater of measured two-minute use and estimate p50, plus 25%. Native CPU accounting uses live measured use; missing or stale measurements use the estimate (or the reservation for older leases). Status and probe publish the same committed CPU totals for the spawn gate.
