- Pull hand-over: gex45 declares no `reaches`, so it pushes nothing; each queued agent heavy toolchain run (`cargo`, `rustc`, `cargo-nextest`, `bun`, `nix`) opens a socket beside its admission ticket. The laptop's `capacity-taker` service runs `north capacity offload take`, which picks the target with the most free cores beyond its admission limit's interactive reserve among itself and the other build hosts it reaches, takes nothing during the game reserve, and calls `north capacity host hand-over` over its own ssh connection. The verb claims the oldest run by renaming its socket, so two takers never take one run; the lane streams down the connection, the target runs it under its own heavy admission, and output and exit code stream back as frames. A taker that refuses, cannot rebuild the lane or leaves before the exit frame gives the run back to the queue at its own place, offered again after 15 s. The taker logs `PULLED host=TARGET owner=OWNER from=SOURCE` and restarts onto a promoted runtime (north#634, #676, #677; docs/rationale/pull-hand-over.md).
