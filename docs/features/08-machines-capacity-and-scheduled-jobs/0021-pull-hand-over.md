- Pull hand-over: a host that declares no `reaches` (gex45) pushes nothing, so its queued agent heavy runs (`cargo`, `rustc`, `cargo-nextest`, `bun` or `nix`) each open a socket beside their admission ticket, and a host that reaches it runs `north capacity offload take` (the `capacity-taker` user service on the laptop), which polls over ssh, checks its own room (free cores beyond the admission limit's interactive reserve, no land check waiting, CPU pressure, memory, disk, counting runs it took that have not started) and then calls `north capacity host hand-over` on the polled host. That verb connects to the oldest queued run that answers; the run streams its lane (the bundle and diff `offload` ships) down the same connection, the taker rebuilds it and runs it under its own heavy admission, and the output and exit code stream back as frames, so the run on gex45 ends with the taker's exit code. The taker refuses any offer whose paths climb out of the lane, whose head is not a commit id or whose command is not a toolchain program, and logs `taker: took OWNER from HOST` for each run (north#634, 2026-11-06; design in docs/rationale/pull-hand-over.md).
