- Private checks: `north private-check [--config PATH] [--check NAME] [--dry-run [--ref REV] [--since REV]]` runs the checks of `north-data/private-checks.toml` (built into the binary; `--config` reads another file) that need a GPU or private art and so cannot run on hosted runners or in the confined farm-runner containers. Each `[[check]]` names a GitHub `repo`, the `checkout` under `~/code`, a status `context`, git pathspec `paths` and `[[check.step]]` tables (`command`, `dir` inside the checkout, machine-capacity `class`, `timeout_seconds` up to 3600). Per check it fetches origin/main in its own worktree `~/code/CHECKOUT/worktrees/private-check-NAME`, created detached and locked so lane-gc keeps it, and skips a tip already judged; when the diff since the last judged tip (`~/.local/state/north/private-check/NAME.json`) touches none of the paths it records the tip without running. Otherwise it checks out the tip, posts a `pending` status, runs each step under `machine-capacity run --class CLASS --owner private-check:NAME`, and posts `success` on the last step's exit 0, `failure` on exit 1 and `error` on any other exit or a failed earlier step, the description being the last step's last stdout line cut to GitHub's 140 characters; a step machine-capacity never admitted (exit 75) posts no verdict, records nothing and makes the run exit 75, so the next run retries it; the tip is recorded only after that status posts, so a failed post retries next run. A per-check lock keeps one run at a time. `--dry-run` runs the steps but prints each `POST .../statuses/SHA` request instead of posting and records nothing; `--ref` and `--since` (dry run only) choose the judged commit and the diff base. The shipped `readability` check (Tom's gate 147, 2026-11-01) runs Mak'gora's `tools/stage/nativeSeparation.ts` as a gpu step; the Wisp window library it needs is a cargo release build on a new Wisp pin, which under the gpu lease (1 CPU, 2 GiB) would run nested and uncounted, so a heavy step builds it first and is a no-op once the pin's library is cached.
