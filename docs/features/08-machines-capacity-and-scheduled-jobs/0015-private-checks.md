- Private checks: `north private-check` runs the checks of `north-data/private-checks.toml` that need a GPU or private art and so cannot run on hosted runners or in the farm-runner containers. Per check it fetches the repository's origin/main into its own locked worktree, skips a tip already judged or one whose diff touches none of the check's paths, runs each step under a machine-capacity lease and posts the verdict as a GitHub commit status; a step capacity never admitted posts nothing and is retried on the next run. `--dry-run` prints the status requests instead of posting. The config schema and verdict rules are in its usage text.
