- Home move plan (north#992): `north home move [--dry-run] PLAN.tsv` applies each `FROM<TAB>TO` row as one rename of an entry directly under `$HOME`, from outside the worker sandbox, whose Landlock domain refuses a rename out of home with EACCES. A row may name `$HOME`, `~` or an absolute path, and the destination must lie under `$HOME`; the move never copies and never deletes, the destination must not exist (RENAME_NOREPLACE) and both paths must be on one filesystem. It refuses a dotfile or dot-directory, a git checkout, the `~/code` container, a destination reached through a symbolic link (the rename opens the destination's directory beneath `$HOME` with RESOLVE_BENEATH and RESOLVE_NO_SYMLINKS), a source that holds the plan or its log, and either path when a config under `~/.config` or `/etc/systemd`, a user unit, or a live process's working directory, executable or open file names it. Each completed row is appended as `FROM<TAB>TO` to `moves.tsv` beside the plan before it is reported; a refused row is named on stderr with its reason and the rest of the plan still runs. `--dry-run` checks every row and prints the moves without moving or logging anything.
