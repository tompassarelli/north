- Rest check: `capacity-watchdog rest-check [--seconds N] [--expected FILE] [--observed FILE] [--save FILE]` compares what is running on the host with its expected-at-rest set and exits 1 when anything is not at rest. It compares running system and user services and scopes, active timers and listening sockets (`PROTO ADDR:PORT UNIT`, `-` for a gone creator such as kernel WireGuard) with the set in `~/.config/capacity-watchdog/rest.json`, declared in firn as `myConfig.modules.capacity-watchdog.rest`. It measures each unit's CPU and context switches over N s (default 30), prints extra units, sockets and over-budget units, and lists claude/codex/tmux sessions as agents.
