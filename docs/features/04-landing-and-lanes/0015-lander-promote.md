- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander` (its unit sets `NORTH_RUNTIME_LINK` to it, so the retire watch follows that link and a lander-input commit to main no longer retires it), and `north land promote [--dry-run] [--shadow-minutes N] [--repo DIR]... [--checker PROGRAM]` moves it. Promotion takes the runtime `current` points at and has its `tree/bin/north` replay, through `north land replay`, the latest 8 recorded rounds in each repository's queue `done/` records: a landed round is its lanes grouped by `landed SHA`, rebuilt on the first-parent ancestor of that SHA the lanes' commits account for, and a `failed` or `conflict` lane is rebuilt alone on main as of its decision. The replay builds the candidate in its own `lander-replay` worktree on branch `land-replay`, runs the checker with no push path, and prints each round with its recorded and replayed verdict; a round whose lane commits are gone is skipped as not replayable. When every replayed verdict matches, the candidate replays a copy of each repository's pending queue on current main every 30 seconds for N minutes (default 15, 0 for one pass) and prints the shadow result; an error seen twice refuses. Only then does promotion swap the lander link atomically and run `systemctl --user restart north-land*`; `--dry-run` stops before the swap. Any mismatch, repeated error, or no replayable round leaves the link unchanged and exits 1 (north#360: the lander retired on every lander-input commit to main on 2026-11-05).
