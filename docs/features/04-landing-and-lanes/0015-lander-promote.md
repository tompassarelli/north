- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a commit to main that changes the lander's inputs no longer retires it (north#360), and `north land promote` is the one way that link moves. Promotion has the runtime `current` points at replay the latest recorded rounds from each repository's land queue through `north land replay`, each refused lane on the main its ticket records under `decided_on`, then shadow the pending queue on current main for `--shadow-minutes`, and swaps the link only when every replayed verdict matches and no error repeats; promotion restarts no unit, so each lander whose inputs changed finishes its in-flight after-landing runs, exits and is restarted on the new link by systemd (north#639); any mismatch leaves the link unchanged and exits 1, and `--dry-run` stops before the swap. After every runtime promotion on a host that has the lander link, `north runtime promote` runs this promotion itself with a 3-minute shadow and logs `lander link held: REASON` to `runtime-follow.log` when it refuses, so the link follows each healthy runtime with no one running the command (north#633).
