- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a commit to main that changes the lander's inputs no longer retires it, and `north land promote` is the one way that link moves (north#360: on 2026-11-05 the lander retired on every such commit). Promotion has the runtime `current` points at replay the latest recorded rounds from each repository's land queue through `north land replay`, each refused lane on the main its ticket records under `decided_on`, then shadow the pending queue on current main for `--shadow-minutes`, and swaps the link and restarts the `north-land` units only when every replayed verdict matches and no error repeats; any mismatch leaves the link unchanged and exits 1, and `--dry-run` stops before the swap.
