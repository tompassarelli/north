- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a commit changing the lander's inputs no longer retires it (north#360), and `north land promote` is the one way that link moves. The runtime `current` points at replays the latest recorded rounds of each repository's queue through `north land replay`, each refused lane on the main its ticket records under `decided_on`, without the live-state lane gates (debt ceiling, runtime floor; north#678), then shadow the pending queue on current main for `--shadow-minutes`, and swaps the link when every replayed verdict matches (or fails only as the held runtime does, north#634) and no error repeats; promotion restarts no unit: each lander whose inputs changed exits and systemd restarts it on the new link, rerunning each journaled after-landing run (north#639); a mismatch leaves the link and exits 1; `--dry-run` stops before the swap. After every runtime promotion on a host that has the lander link, `north runtime promote` runs this promotion itself with a 3-minute shadow and logs `lander link held: REASON` to `runtime-follow.log` when it refuses, so the link follows healthy runtimes (north#633).
