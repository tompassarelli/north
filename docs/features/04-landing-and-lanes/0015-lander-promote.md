- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a commit changing its inputs no longer retires it (north#360), and `north land promote` is the one way that link moves. It replays the latest recorded rounds of each repository's queue through `north land replay` on the main each ticket records under `decided_on`, without the live-state gate (runtime floor; north#678), shadows the pending queue on current main for `--shadow-minutes`, and swaps the link when every replayed verdict matches (or fails only as the held runtime does, north#634) and no error repeats; landers whose inputs changed restart on the new link and rerun journaled after-landing runs (north#639); a mismatch a `Replay-change: land.<kind> <reason>` trailer declares follows; an undeclared one is bisected to its commit, reverted and holds with exit 1, and a replay that reached no verdict, with fewer than 2 rounds matched, holds nothing and exits 75 to retry, while beside 2 or more matched rounds and no divergence it is reported and the link moves (north#842) (docs/rationale/replay-divergence.md); `--dry-run` stops before the swap. Its replays run their land checks on a build host and reach no verdict when none answers, never on the lander host (north#634). `north runtime promote` runs it after every runtime promotion with a 3-minute shadow; a promotion that finds another holding `lander-promote.lock` exits, and the holder replays again when `current` moved during its replay, so a burst of landings gives one replay of the newest runtime (north#634), logging `lander link held: REASON` in `runtime-follow.log` (north#633).
