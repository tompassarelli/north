- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a landing that changes its inputs does not retire it, and `north land promote` is the one way that link moves (north#360). It points the link at the newest runtime whose canary passed, then judges that runtime in a unit of its own, `north-lander-replay.service`: the latest recorded rounds of each queue are replayed on it and the pending queue is shadowed, and a verdict the held runtime does not share moves the link back to the last judged runtime and names the candidate as refused (north#634, north#1183). Each runtime promotion runs it, and `--dry-run` stops before the link moves. Why it is judged this way, and what a divergence does: docs/rationale/replay-divergence.md and docs/rationale/lander-doctor.md.
