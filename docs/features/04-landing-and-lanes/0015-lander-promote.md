- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a commit changing its inputs no longer retires it (north#360), and `north land promote` is the one way that link moves. It replays the latest recorded rounds of each repository's queue through `north land replay` on the main each ticket records under `decided_on`, without the live-state gate (runtime floor; north#678), shadows the pending queue on current main for `--shadow-minutes`, and swaps the link when every replayed verdict matches (or fails only as the held runtime does, north#634) and no error repeats; landers whose inputs changed restart on the new link and rerun journaled after-landing runs (north#639); a mismatch a `Replay-change: land.<kind> <reason>` trailer declares follows; an undeclared one is bisected to its commit, reverted and holds with exit 1, and a replay that reached no verdict holds nothing and exits 75 to retry (docs/rationale/replay-divergence.md); `--dry-run` stops before the swap. `north runtime promote` runs it after every runtime promotion with a 3-minute shadow, logging `lander link held: REASON` in `runtime-follow.log` (north#633).
