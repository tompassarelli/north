- Lander promotion: the lander runs from its own runtime link, `~/.local/state/north/lander`, so a commit changing its inputs no longer retires it (north#360), and `north land promote` is the one way that link moves. It applies land-first to the link: it points it at the newest runtime `current` names as soon as that runtime's canary passed, then the recorded-round replay and shadow judge it in `north-lander-replay.service`, a unit of its own that `north land promote --judge` runs and that outlives the promotion and any order that ran it, so the promotion returns once the link moved; the unit logs its verdict to `~/.local/state/north/lander-replay.log`, a newer promotion stops it before it moves the link and keeps `lander-rollback`, which only a verdict releases, so it judges against and rolls back to the last judged runtime rather than the unjudged one it replaces, and a promotion whose unit cannot start replays inline (north#1183). The replay runs the latest recorded rounds of each repository's queue through `north land replay` on the main each ticket records under `decided_on`, without the live-state gates (north#678), and a landed round's replay checks the commit it landed as, the tip its `landed` verdict records, rather than rebuilding the candidate from the lane heads, so the generated registries the lander wrote at land time are already in it and a generator that no longer covers the round's tree cannot fail the replay (north#902), and the shadow runs the pending queue on current main for `--shadow-minutes`; a candidate whose verdict matches (or fails only as the held runtime does, north#634) stays, and a divergence the held runtime does not share moves the link back to the held runtime and names the candidate in `lander-refused` until current moves on, as the doctor's rollback does; landers whose inputs changed restart on the new link and rerun journaled after-landing runs (north#639); a mismatch a `Replay-change: land.<kind> <reason>` trailer declares follows; an undeclared one is bisected to its commit and the link goes back while the revert is queued, with exit 1; a replay that reached no verdict, with fewer than 2 rounds matched, leaves the link on the candidate and exits 75 to retry, while beside 2 or more matched rounds and no divergence it is reported and the link stays (north#842) (docs/rationale/replay-divergence.md, north#902); `--dry-run` stops before the link moves. Its replays run their land checks on a build host and reach no verdict when none answers, never on the lander host (north#634). `north runtime promote` runs it after every runtime promotion with a 3-minute shadow; a promotion that finds another holding `lander-promote.lock` exits, and the holder replays again when `current` moved during its replay, so a burst of landings gives one replay of the newest runtime (north#634), logging `lander link held: REASON` in `runtime-follow.log` (north#633). A runtime a rollback held off the lander is retried once no repository has landed a lane for 15 minutes since the hold began, since only a landing moves `current` and a held lander lands nothing, and the doctor starts that retry each 30 minutes while the hold lasts; `north land promote` and `north land doctor` page the proxy and the lander's lead once, under one condition per run of failures, when a lander unit has been restarted 3 times and is not running, with the last lines of its journal as the cause (north#892).
