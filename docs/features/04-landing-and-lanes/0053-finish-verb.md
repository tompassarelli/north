- `finish` is the one tool call a headless Claude fleet session finishes its lane with, offered beside `hand-in` (`harness/worker-tools.toml`) and named by the worker's instructions as the way to finish. `north finish --check COMMAND --message TEXT -- PATH...` resolves the lane from the named paths with hand-in's refusals, runs COMMAND with `sh -c` in the lane root and, only when it exits 0, commits the changed named paths and takes the `safe-push --to main` road without `--wait`, so every gate runs as before and the call returns at `Done: queued ..., ticket NAME` instead of waiting for the lander. A failing check stages, commits and queues nothing and returns its output with `NOT committed, NOT queued` (north#1194).
