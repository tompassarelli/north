- `north capacity offload choose|run` (north#658): while this host is in game-reserve, `safe-push` ships the lane by git bundle to the first other `[hosts.NAME]` host with room and runs the land checks there; `choose` picks the host and `run` runs one check on it and fails unless the remote reports its exit status. `land.local-only` entries keep their checks on this host, and a repository that names a `land.workflow` runs its checks on GitHub Actions instead. A `land.host-input` entry in `.safe-push` sends a check only to a host that holds the files it reads.
