- Fleet landings: fleet exports `NORTH_FLEET_SESSION` to every command a session runs, `safe-push` logs that name in `pushes.tsv` with the default-branch commit it landed, and north records that commit as the landing of the session's task (its `--task`, else the session name) when each turn ends and every 30 s while the fleet screen is open, so `north task landed` is optional. Only a lander serving a checkout under the code root (`NORTH_CODE_ROOT`, else `~/code`) writes landings to the host's log; a scratch lander writes to the log `NORTH_PUSH_LOG` names, else nowhere, so a hand-run lander on a scratch repository never credits its landing to the session that ran it.
