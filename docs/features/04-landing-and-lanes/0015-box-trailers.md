- Box trailers: a lane's commit carries `Item: REPO#N` and `Box: TEXT` trailers naming the box it closes, which `north work brief new` prints and `north cloud land` keeps when it folds a handback. A launch keeps its brief's item, box and Done-when command in the lane (`north finish --brief-trailers`), and the session's `north finish` and `north hand-in` add `Item:` to a message that names no item, which restores the issue on the commit and ticks nothing. Only `north finish` adds `Box:`, and only when its check command is the brief's Done-when command and the message has no `Box:` line, so a commit carries the box exactly when the call has just run and passed the command that completes it; a hand-in, a finish with another check and a brief with no Done-when command never add it (north#1367). The landing reads no issue: it neither checks a `Box:` against its issue nor ticks a box or closes an issue after it lands (north#1650).
