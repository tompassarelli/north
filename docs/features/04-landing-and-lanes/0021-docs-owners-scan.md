- Plan documents name their owners: `north land scan docs-owners BASE..HEAD`, which safe-push runs before every push, looks at the `docs/` Markdown files (outside `docs/references/` and `docs/features/`) whose name has the word plan, port, migration or order. It refuses any such document whose owners are all closed in the GitHub mirror's copy (`~/.local/state/north/github-mirror.db`, no API call; an owner the mirror does not know counts as open), and, for a document the push adds or changes, one with no `Owners: REPO#N, #M` line or one backticking a repository path that does not exist (a `Creates:` line lists files the work will add). It reads the tree once and runs in well under a second. A finished plan is deleted, or rewritten to describe what shipped under a name without those words. Why is in north#635.
