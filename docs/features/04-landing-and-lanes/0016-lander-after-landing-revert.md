- Lander after-landing revert: the lander pushes a candidate after only the seconds-long checks (clean pick, outgoing scans, stale-revert and trailer gates) and runs every `land.after` line once per landed batch on main. A red run bisects the landed lanes by running the after set on each prefix, reverts exactly the first lane whose prefix is red as a red-fix ticket that lands ahead of the queue (`Reverts:` trailers on every commit of the lane), and tells the lane's session to re-queue it with `Follows:`. A red fix whose own run is red is never reverted again; the proxy is alarmed instead.
