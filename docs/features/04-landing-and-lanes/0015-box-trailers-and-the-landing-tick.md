- Box trailers and the landing tick: a lane's commit carries `Item: REPO#N` and `Box: TEXT` trailers naming the box it closes, which `north brief new` prints and `north cloud land` keeps when it folds a handback. `north land scan boxes BASE..HEAD` refuses a `Box:` with no `Item:` before it or one matching no single unticked box. After a landing, `north after-landing` (safe-push's direct and train paths, the lander's follow step) first runs `north task check --done-when --box TEXT REPO#N` per trailer, which ticks a box naming its own ``Done when: `CMD` `` with its `Evidence:` stamp when the command passes, the stamp the closed-box report counts as checker-verified. It then queues one tick per trailer in the issue-body outbox and drains it: the box is ticked with its landed sha, a parent with it once every box under it is ticked, and the issue closes once every box is ticked. A box with its own command, a box marked `(observed)`, `(headless run)` or a Tom check, a box with unticked boxes under it, and an issue with no checkboxes get no such tick and a refusal note naming why. Why is in docs/rationale/proxy-role.md section 4.
