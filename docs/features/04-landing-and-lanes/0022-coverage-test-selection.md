- Coverage test selection: `north test coverage refresh` records on a check host which functions each Rust test executes, and the change graph turns that map into the tests a lane's change can reach, so a landing runs those tests and not the whole suite. `north test coverage select BASE HEAD` prints the selection by hand, and `north test coverage miss` names the after-push failures the selection would have skipped and refreshes the map. A change the map cannot place widens the selection to the file or crate that holds it, and the full suite still runs after every push. The map refreshes nightly and whenever it is a day old, a miss is recorded or too many of a lane's tests are unknown to it (north#944, north#1039, north#1099). How it is recorded and measured: docs/rationale/coverage-test-selection.md and docs/rationale/test-selection.md.
