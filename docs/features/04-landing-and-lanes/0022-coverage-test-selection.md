- Coverage test selection: `north coverage refresh` records, on a check host through `north capacity offload run`, which functions each Rust test executes. It builds the workspace tests with `-C instrument-coverage`, runs nextest with `north coverage exec` as the runner so each test writes its own LLVM profile, and keeps the map in `~/.local/state/north/coverage/REPO.json` along with the commit it was recorded at. Before the push, the `coverage test` land check picks the tests that reach the functions the lane changed and runs them by exact name on a check host. A function edited since the map was recorded selects every test reaching its file. Some changes run no tests before the push: a line outside every function (a constant, a type, a macro, a new test), an input the map does not trace (Cargo.toml, build.rs, a new file, a run-time table), a map over 3 days old, or a selection of over 400 tests. `north coverage refresh --repo north` runs nightly from nixos-config. The full suite still runs after the push (north#634).
