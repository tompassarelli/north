- Coverage test selection: `north coverage refresh` records, on a check host through `north capacity offload run`, which functions each Rust test executes. It builds the workspace tests with `-C instrument-coverage`, runs nextest with `north coverage exec` as the runner so each test writes its own LLVM profile, and keeps the map in `~/.local/state/north/coverage/REPO.json` along with the commit it was recorded at. Before the push, the `coverage test` land check picks the tests that reach the functions the lane changed and runs them by exact name on a check host. A function edited since the map was recorded selects every test reaching its file. A line outside every function (a constant, a type, a `use`, a macro), a file with no mapped function, and a run-time input that Rust sources name (help.txt, a harness table, .safe-push) select every test reaching the whole file or the sources naming it; a test the lane adds runs by name. Some changes run no tests before the push: Cargo.toml, Cargo.lock, build.rs or another toolchain input, an input no Rust source names, a file whose crate has no mapped function, a map over 3 days old, or a selection of over 400 tests. `north coverage refresh --repo north` runs nightly from nixos-config. The full suite still runs after the push (north#634).
