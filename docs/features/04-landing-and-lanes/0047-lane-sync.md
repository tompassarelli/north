- Main checkout sync (north#1097): `north lane sync CHECKOUT...` fetches origin and fast-forwards each project main checkout (`.../PROJECT/main`) by the step `north config agents sync` makes, clearing untracked files whose bytes equal the incoming blob. A worker session runs it in place of a bare `git merge --ff-only`, which stops at the first file it cannot replace and leaves the new files untracked in a stale main, so `north lane remove` measured lanes against the stale branch. The primary-checkout hook's lane advice names this verb. A checkout that is off main, ahead of origin, dirty or holds differing untracked files is left as it is with the reason named. `north lane remove` measures a lane against its main's upstream `origin/main`, not the local branch (north#1036).
