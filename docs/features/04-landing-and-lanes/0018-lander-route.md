- Lander route: `safe-push --to main` asks `north land route` whether the lander takes the lane. A committed `.safe-push` on origin's main with `landing.queue` unset or `lander` queues the lane through `north land enqueue` on `landing.lander-host` or a host in `landing.remote-hosts`, refuses `--direct`, and refuses any other host naming `landing.remote-hosts`; with those hosts set only in the machine's git config, the named host queues a one-commit lane and every other lane lands per lane, as does `landing.queue = lock`. A per-lane answer exits 3 and safe-push lands the lane itself (north#360).
