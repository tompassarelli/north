- Background offload slot: `north capacity offload run --background`, which `north mutant sweep` uses, runs its command in the checkout's one `<checkout>.background` slot on the build host instead of a land-check slot. Its queue ticket ranks behind every land check and worker build, it is not held to the job cap, and land checks do not count it against theirs, so an hours-long sweep leaves every land-check slot free (north#661).
