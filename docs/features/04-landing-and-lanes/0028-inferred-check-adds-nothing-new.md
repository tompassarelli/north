- Inferred land check that main fails too: a repository with no `.safe-push` land.check lines gets `cargo test` and `cargo clippy -D warnings` inferred from its tree. When such a check fails on a lane and also fails on the base tree, the lane passes only if it adds no finding the base lacks: the failing tests and the compiler or clippy diagnostics of the lane's log, each keyed by message and file and never by line, are compared with the base run's, recorded beside its result for the round. A lane that adds any finding fails as itself, naming the first five, and a base whose findings were not recorded cannot excuse a lane (north#633, north#634).
