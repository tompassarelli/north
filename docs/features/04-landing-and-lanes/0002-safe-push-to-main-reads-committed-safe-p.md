- `safe-push --to main` reads committed `.safe-push` `land.check` entries (`pathspec[,pathspec] :: command`) and runs affected checks, on GitHub Actions through `north land-actions` when `land.workflow` names a workflow and here for each `land.local-only` (`reason :: command`); `land.publish = PREFIX` pushes the scanned lane to `PREFIX<sha12>` for the checks run here (`SAFE_PUSH_LAND_REF`) and deletes it after; Main is red confirms a failed job once and reverts a culprit after a green parent. Before running them it asks `north land-cache hit` and skips (printing `land check: COMMAND reused (passed for these inputs at TIME, SHA)`) each check that already passed for the same inputs: the sha256 of the command line, the host class that runs it (`local`, the offload host, or `actions`; a verdict from one class never decides another), the toolchain identity (`flake.lock`, `rust-toolchain.toml` and `rust-toolchain` object ids at the head), the git object ids at the head of exactly the paths in that check's `.safe-push` filter (`**` is the whole tree) and, for a check that reads `~/code/south` or `~/code/nixos-config`, those checkouts' HEADs, stored under `~/.local/state/safe-push/land-cache`; a pass is recorded after the check (or the Actions batch) exits 0, and a failure deletes the record.
