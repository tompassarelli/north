- `safe-push --to main` runs the lane's affected land checks from the committed `.safe-push` (`land.check`, `land.local-only`, `land.machine-bound`, `land.runner`, `land.workflow`, `land.publish`): on GitHub Actions through `north land-actions`, on the build host, or here. Before each check it asks `north land-cache hit` and reuses a pass recorded for the same inputs (the command, the host class that ran it, the toolchain and the object ids of the check's paths), so an unchanged check never runs twice; a failure deletes the record. `safe-push --help` and `north land-cache --help` are the contract.
