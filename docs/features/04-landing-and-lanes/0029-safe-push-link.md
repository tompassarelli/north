- `safe-push` is the north binary entered through a link: the runtime installer writes `tree/bin/safe-push -> ../../north` in every runtime, so `~/.local/bin/safe-push` resolves to `runtimes/<sha>/north`, and north dispatches on argv[0] (`north safe-push ARGS` is the same entry). The land-check runner runs the publication scan with argv[0] `safe-push`, so a path that resolves to north still selects the entry, and the after-landing gates run the running binary's `code-health` (docs/rationale/safe-push-composition.md, north#621).
