- Fails-first gate: `north land-fails-first [BASE HEAD]`, a `.safe-push` land check, runs the tests a lane adds or changes against base with the head's test files: a lane that changes code needs at least one of them to fail on base, and a lane marked `Behavior: unchanged` needs all of them to pass. It then runs those tests concurrently several times (the `[flake]` section of `.safe-push`) on the lane head and refuses a lane naming any test that fails a run as flaky, never retrying to green. The contract is `north land-fails-first --help` and why is in docs/rationale/failing-first.md.
