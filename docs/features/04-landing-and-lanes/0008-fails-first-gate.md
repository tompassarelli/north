- Fails-first gate: `north land-fails-first [BASE HEAD]` (a `.safe-push` land check for lanes touching `crates/` or `tests/`, reading `SAFE_PUSH_LAND_BASE` and `SAFE_PUSH_LAND_HEAD`) applies when the lane changes both code (under `crates/` or `src/`) and test files (under a `tests/` directory or named `*_tests.rs` or `*_test.rs`); it checks out base with the head versions of the changed test files and runs, through the base `mutant.run` runner, only the `#[test]` and `prop_` functions whose lines the lane adds or changes. An unmarked lane needs at least one of them to fail on base (a test that does not compile or does not exist on base counts as failing); a lane whose head commit message has a line `Behavior: unchanged` needs all of them to pass on base. Exit 0 passes, 1 refuses with the test names, 75 means the check could not run.
