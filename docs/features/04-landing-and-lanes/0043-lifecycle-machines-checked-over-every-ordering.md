- Lifecycle machines checked over every ordering: `north check machines [--write | --registry | --fixes [--days N] | --replay [--days N]] [--root DIR]` drives each registered machine's own `Lifecycle` table through the real lifecycle store over every ordering of a stated scope (one instance; three processes, two on one host; every move for every holder; the holder's death; the dwell running out) and exits 1 with each broken promise and the shortest ordering that shows it. The landing runs it on a lane that changes the kernel, a machine's table or a chart, and on every code lane refuses an `impl Lifecycle for` that the registry in `src/cli/machines.rs` does not name. `--write` regenerates each machine's state chart under `docs/rationale/state-machines/`, and a stale chart fails the check. `--fixes` lists the machines whose code a landed incident fix changed, which the flow detector `machine-fix` files as one box per machine and week on the owner of `docs/rationale/state-machines.md`; the detector `machine-refusal` files a box for a move the lifecycle store refused. `--replay` scores that trigger over history beside weekly, monthly and churn-placed sweeps (north#1042, `docs/rationale/watch/2026-11-10-pstack-verification.md`).
