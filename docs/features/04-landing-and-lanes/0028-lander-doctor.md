- Lander doctor: `north land doctor [--dry-run]`, run every 2 minutes on the lander host before each `north-land-shadow` tick, prints each lander bound with its live value and limit and the remedy it applied. The bounds are the oldest queued lane, the time since the last landing, round silence, lander link lag and held minutes, slot hold ages, free disk and stale worktree registrations on each host, infrastructure-failed checks, queues no checkout serves, empty queues left with only logs and watchdog rounds, and toolchains built from source. The remedies, in order, prune missing worktree registrations, end a slot's job past its deadline, requeue an infrastructure failure once, remove an orphan queue no checkout serves and no ticket waits in, evict offload caches under disk pressure, restart a silent lander unit, then roll the lander link back to the last build that landed a batch green and keep `north land promote` off the bad one. Each remedy writes one incident row; an unknown state, or a remedy that did not clear its bound in 5 minutes, messages the proxy once per episode. Every repository gets its lander from nixos-config's one north-land list: safe-push's route refuses a lane for a repository that list does not name, and the doctor pages for a queue no lander serves. It also asks GitHub with a North Lander installation token whether every repository a `north-land@` unit or a `.safe-push` config names is reachable, and fails naming each repository the installation cannot reach. See [docs/rationale/lander-doctor.md](../../rationale/lander-doctor.md) (north#634).
