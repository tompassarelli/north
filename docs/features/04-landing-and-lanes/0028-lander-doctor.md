- Lander doctor: `north land doctor [--dry-run]`, run every 2 minutes on the lander host before each `north-land-shadow` tick, prints each lander bound with its live value and limit (oldest queued lane, since the last landing, round silence, lander link lag and held minutes, slot hold ages, free disk and stale worktree registrations on each host, infrastructure-failed checks, toolchains built from source) and the remedy it applied: prune missing worktree registrations, end a slot's job past its deadline, requeue an infrastructure failure once, evict offload caches under disk pressure, restart a silent lander unit, then roll the lander link back to the last build that landed a batch green and keep `north land promote` off the bad one. Each remedy writes one incident row; an unknown state, or a remedy that did not clear its bound in 5 minutes, messages the proxy once per episode. Every repository gets its lander from nixos-config's one north-land list: `north land route` refuses a lane for a repository that list does not name, and the doctor pages for a queue no lander serves. See [docs/rationale/lander-doctor.md](../../rationale/lander-doctor.md) (north#634).
