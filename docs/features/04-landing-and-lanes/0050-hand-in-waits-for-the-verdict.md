- `safe-push --to main --wait` is the one call a fleet session hands in with: it queues the lane, waits up to 25 minutes for the lander and prints `Done: landed COMMIT on main`, or exits 1 with why the lane did not land. On the lander host it reads the ticket the lander decided; on a host that queues through its outbox it reads the decided ticket the lander writes back into that outbox as it decides, the mirrored lander records as a second path, and origin until the destination holds the lane. A verdict counts only from a ticket with the hand-in's own name, head and branch, and a landed verdict only once origin holds its commit. After 60 s with no verdict it asks the lander where the ticket stands and prints the answer, or that the lander did not answer (north#1185). A fleet session keeps its 30 s foreground default and may ask for a longer `timeout` for this call only (`BASH_MAX_TIMEOUT_MS`), the fleet prompt names it as the only hand-in, and the worker-wait guard lets that call alone run in the foreground (north#1138).
