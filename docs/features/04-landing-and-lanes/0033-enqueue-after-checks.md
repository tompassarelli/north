- Enqueue runs the cheap after-landing checks: a `land.after` line in `.safe-push` whose paths list carries `@enqueue` also runs in `north land enqueue` beside clippy, before the ticket is written while `landing_refusals` is `enforce` (in `shadow` only clippy runs there), so a lane that fails one is refused in the worker's turn instead of after the lander's queue wait. The checks are citations, the verbs sort, the owners check, code-health layers and the tests/it module list; they run on the lane's tree, and the lander still runs the same line after landing. The features and rationale indexes are land-only checks: the lander regenerates each index from the lane's per-unit sources before it runs them, so a lane never needs to (or may) commit a generated index. `--no-build` is dropped for the early run so a checker the live runtime does not cover is built from the lane's tree, and checks that need the merged candidate stay after-landing only (north#697). Before them, enqueue folds the mechanical facts into the lane: it sorts each `sorted` block (the verbs table), amending the lane's last commit, so an out-of-order verb never refuses a lane. It no longer regenerates the `regenerate` indexes of `harness/merge-sets.toml`: those are written by the lander's candidate after it picks a lane whose sources changed, and `north land scan generated-registry` refuses a lane that commits one, so a generated file never enters a worker's diff (north#729, north#1057). A `land.check` line marked `@enqueue` runs at enqueue in either mode: the policy check `agent-config-check tree-policy` refuses a lane that edits harness text past a skill's byte cap with the overage in the worker's turn, where it used to refuse only at the lander (north#729). The other `land.check` scans that judge only the lane's own diff and build nothing are marked `@enqueue` too: code-health layers, experiments, citations, gate-shadow, the verbs sort, the tests/it module list, the nix lock, nix-entry, safe-push-verbs and run-time-data. A lane failing one is refused before its ticket is written, not in every probe of a round. On 2026-11-08 n882-context failed layers and experiments in about 10 probes; replayed at its head, the two refuse in 4.3 s and 0.02 s (north#842).
