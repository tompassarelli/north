- Root commit on an empty origin: when `safe-push --to main` finds origin with no branches, it runs the dry run's secret and privacy scans and land checks on the lane, then pushes the lane's commit as origin's main directly, with a lease that requires the branch to be absent, because there is no queue to wait in and no `origin/main` to rebase onto. The dry run and the real run share their gates; an origin that has other branches but no main still queues and refuses as before.
