- Sheriff for any red main: when an after-landing run is red and its own batch names no culprit, the sheriff takes every failing check from the run, named tests and failing steps alike (a clippy, lint, scan or code-health step names no test, and its outcome file names the step), reruns them at main's current tip, which may be past the red head, and acts only on a verdict: a pass there means a later landing fixed it, and a rerun that reaches no verdict reverts nothing. When they still fail it bisects the landings from the last green after-landing verdict to the tip by rerunning only those tests or steps (`north land checks --after --command STEP`), confirms by rerunning them on the tip without the suspect, and queues that revert ahead of the queue. Every step writes a land.sheriff decision record. The reverted lane's session hears of the revert with the failing checks and the log path if it is idle or working; otherwise the sheriff launches a fresh worker on the same box whose brief carries `Follows:` the reverted lane and that evidence, and tells the proxy (north#634).
