- One lander per repository: `north land serve --repo DIR` without `--all` serves only that repository's queue (`~/.local/state/north/land-queue/<origin key>/`) and takes an exclusive `flock` on `lander.lock` in it, writing `pid N serving DIR` there. A second lander on that queue, per-repository or `--all`, exits 1 with `queue ... is already served by pid N serving DIR; refusing to serve it twice`; `--all` instead skips a queue another lander holds, says `not serving` once, and retries it at the next discovery. Each lander reaps and tags its remote offload runs with its own owner, `north-land-<origin key>`, so a restart of one repository's lander never reaps another's checks, and a repository whose rounds error backs off 60, 120, then 240 seconds, alarming the proxy at the third, without delaying any other repository (north#360).
