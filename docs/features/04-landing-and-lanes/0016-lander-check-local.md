- Lander local pre-push checks: `land.check-local = true` in `.safe-push` makes the `land.check` lines run on the lander host alone, with no capacity reservation, offload, build-host runner, Actions dispatch or lane publication, so the seconds-long pre-push set (outgoing scans, trailer gates and the cheap shell lines) never waits for a build slot. The `land.after` set keeps `landing.capacity` and `landing.runner` and runs on a build host after the push.
