- Lander recheck: a green precheck lane lands its checked tree only while its base is still main. When main moved during its check, a lane whose changed files meet main's is checked again in full on the new main, and any other runs only the `[land] recheck` lines of `.safe-push` on the exact tree it would land (`NORTH_LAND_RECHECK=1` selects them in `north land checks`; north runs `cargo check --tests` on the crates the lane affects), or the full check where a repository has none. On 2026-11-05 a lane that added a struct field landed without a second check beside a lane that built the struct in another file, and main stopped compiling for 12 minutes (north#582).
