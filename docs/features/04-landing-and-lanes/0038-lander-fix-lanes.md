- Lander-fix lanes (north#930): a lane whose commit carries a `Lander-fix: REASON` trailer and changes only lander and landing code (the `crates/north-land*` crates, `north-safe-push`, `north-check-environment`, the offload slot code, `tests/it/land*`, the landing docs and the features index) is queued with `lander_fix` set; `north land enqueue` refuses the trailer on a lane that changes anything else and names the files. A lander fix is ordered ahead of every other ticket, Main-red fixes included, so it is the first commit of the lander's one push of the queue and no lane queued before it can conflict it out. When the lander checks only repairs, while the sheriff answers a revert request or the base-broken pause holds, lander fixes land with the Main-red fixes, so the lander never holds back its own repair. The lane passed its own land checks on a build host against main before queueing, as every lane does. It lands by the same lease push and is followed by the same after-landing run and the sheriff's revert as any lane.
