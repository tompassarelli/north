- Lander unfit check host: a precheck that fails only because its check host is unfit is an infrastructure verdict, never a refusal. The lander reads three signatures from the check log: a crate the host's registry lacks offline (`failed to download CRATE` with `--offline was specified`), `north` missing on PATH, and an offload transport failure (a `north capacity offload: ...` line with exit 255, such as `shipping the lander runtime SHA to HOST: rsync ... failed`). It records the verdict as transient `infrastructure: the check host is unfit: ...`, checks the lane again at once on another host through `north capacity offload choose --any --avoid HOST`, and falls back to every host when no other has room; three such verdicts on an unmoved main still escalate as a persistent transient. `north land promote` does not ask a candidate to reproduce a round recorded `failed` whose log carries one of these signatures. On 2026-11-05 lane B (816e9fb68) was refused after its clippy ran on cx53, whose registry lacked ahash v0.8.12, and promotion refused a candidate over n360-s19a's shipping failure (north#360).
