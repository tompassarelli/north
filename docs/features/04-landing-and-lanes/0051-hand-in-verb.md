- `hand-in` is the one tool call a headless Claude fleet session hands its lane in with: north's tool server offers it to every session (`harness/worker-tools.toml`), taking a commit message and the absolute paths the session changed. `north hand-in --message TEXT -- PATH...` stages and commits the changed named paths in the lane that holds them (or queues the lane as it stands when they are already committed, refusing commits that change any other path), refusing a path in another checkout, a checkout on its default branch or paths with no changes before anything is committed, and, inside a worker sandbox, a checkout whose git lock files the session may not remove (another project's lane), which it names with `safe-push --to main --wait` run from that lane as the road, before git touches it, since the sandbox lets git create a lock there but not remove it (north#1172); then runs `safe-push --to main --wait` in that lane, so every gate, the private-kind judge and the lander's verdict come back as the tool result, word for word. The server's call timeout sits above the 25-minute hand-in wait, and `safe-push --to main --wait` stays the hand-in where the tool is absent (north#1158).
