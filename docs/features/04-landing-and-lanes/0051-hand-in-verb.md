- `hand-in` is the one tool call a headless Claude fleet session hands its lane in with: north's tool server offers it to every session (`harness/worker-tools.toml`), taking a commit message and the absolute paths the session changed. `north hand-in --message TEXT -- PATH...` stages and commits exactly those paths in the lane that holds them, refusing a path in another checkout, a checkout on its default branch or paths with no changes before anything is committed, then runs `safe-push --to main --wait` in that lane, so every gate, the private-kind judge and the lander's verdict come back as the tool result, word for word. The server's call timeout sits above the 25-minute hand-in wait, and `safe-push --to main --wait` stays the hand-in where the tool is absent (north#1158).
