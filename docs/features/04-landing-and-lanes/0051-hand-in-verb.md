- `hand-in` is the call a session hands its checked lane in with: north's tool server offers it to every session (`harness/worker-tools.toml`), taking a commit message and the absolute paths the session changed. `north hand-in --message TEXT [--] PATH...` requires the lane to be clean and its current `HEAD` to have passed `safe-push --check-only`, refusing uncommitted changes, a `--message` that rewrites `HEAD`'s message, an unnamed deletion, a path in another checkout, a checkout on its default branch, or, inside a worker sandbox, a ring-0 path or a checkout whose git lock files the session may not remove (north#1172, north#1650); it then runs `safe-push --to main --require-check-only` in that lane and returns at the `Done: queued` ticket without waiting on the lander (north#1632).
