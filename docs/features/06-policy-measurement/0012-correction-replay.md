- Correction replay: `north policy-replay case ID... --arm NAME=GENERATION` measures harness text on real mistakes. Each ID is a correction row of the grounding ledger; the runner cuts that session's transcript before the corrected turn, resumes a fork with `--system-prompt-snapshot off` in a scratch Claude config holding the arm's agent generation (`own` is the one the session ran under, `current` the live one), swaps the generation's changed CLAUDE.md and skill text into the history, records and refuses every tool but reading, and has a judge model grade whether the turn repeats the corrected behavior. Each arm gets 2 samples and a third on disagreement; it prints one verdict per case (fixed, still fails, regressed, not reproduced), and its rows keep each sample's tool calls and final text.
