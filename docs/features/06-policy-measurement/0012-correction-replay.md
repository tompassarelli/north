- Correction replay: `north policy-replay case ID... --arm NAME=GENERATION` measures harness text on real mistakes. Each ID is a correction row of the grounding ledger; the runner cuts that session's transcript before the corrected turn, resumes a fork with `--system-prompt-snapshot off` in a scratch Claude config holding the arm's agent generation (`own` is the one the session ran under, `current` the live one), swaps the generation's changed CLAUDE.md and skill text into the history, records and refuses every tool but reading, and has a judge model grade whether the turn repeats the corrected behavior. Each arm gets 2 samples and a third on disagreement; it prints one verdict per case and lane arm, and its rows keep each sample's tool calls and final text. A case file's `kind` decides the verdict: a bad case is kept when the lane avoids what the base repeats, and a guard or control case (ordinary work the text must not break) holds unless the lane's avoid rate falls below the base's beyond the 90% interval, which reads regressed. Any regressed case refuses the lane: the run exits 1 and names it.
