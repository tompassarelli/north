- Proxy calls: `north proxy calls TRANSCRIPT` reads a Claude Code transcript's main-thread tool calls, skipping subagent calls and repeated tool-use ids, and prints them by kind (delegate, child message, Tom-facing, briefing, monitoring scripts, bookkeeping, hands-on landing and editing, landing logs, status checks, diagnosis), the streaks of calls between hand-offs (delegations, child messages, briefs and Tom-facing calls) with their median, 90th percentile and the counts reaching 5 and 15, and every counted shape (the `north` verb, or the first two words of each stage after any `cd`) run 20 or more times. A `north` command takes the kind its verb declares in the CLI's verb table (`src/cli/verbs.rs`, where a two-word entry overrides its verb for that subcommand and a test fails any dispatched verb without a kind); foreign commands (`git`, `gh`, `threads`, `safe-push`, `sed -i`, `journalctl`, loops, sleeps, helper scripts) go through an ordered rule list, and a call with several stages takes the earliest kind in that order. The classifier, `crates/north-core/src/proxy/`, is pure, so the delegation guard and the daily readout share it (north#112).
