- Deferred checks: a box whose code landed and whose only remaining check is a measurement over time (a day of logs, N ledger runs) moves to a `[[check]]` entry in the same registry, so no worker waits for it. `north experiments defer ISSUE BOX --check CMD --by YYYY-MM-DD [--expect TEXT] [--id ID] [--root DIR]` appends the entry (box text, command, optional expected output, review day, owner issue) under `--root` (default: the current directory, so it lands with the lane) and marks the box `(waits: DAY, ...)` on its issue, closing the issue when only deferred boxes remain. `north experiments judge --file` runs each due check from the repository root (pass: exit 0 and, with `expect`, that exact output; 120 s limit), ticks the box with `Evidence:` on a pass, and on a miss reopens the box with the output and reopens a closed issue. A command that cannot run (exit 126 or 127, or timeout) is tried again on the next tick.
