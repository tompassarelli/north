- Unanswered replies (north#641): the `north hook stop` guard in `crates/north-guard/src/guard/unanswered.rs` runs on the owner's own window and the coordinator's session. When the owner's last prompt asked a question (a question mark or an opening question word such as "did" or "why") and the final reply's first line carries none of a yes or no, a number to a question that asks for one, or a name or fact drawn from the prompt's own words, the hook refuses the end of the turn, at most twice per turn, and names the question so the reply can open with the answer itself. The class `unanswered` in `harness/corrections.toml` names this guard and its `guarded_at`, so a later correction of the class prints red in the coordinator's fleet tick for a week.
