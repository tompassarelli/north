- Policy replay: `north policy-replay` measures how well a policy makes agents behave by replaying scenarios from `south:agents/replay/` through `claude -p` with the policy in place of the live one and scoring each run with the scenario's detector. `run` compares policy arms (and model, effort or advisor overrides) and writes one row per run; `sweep` runs every variant of `variants.toml`, writes per-variant rows the `agents sync` regression gate reads and a candidate operating point with the fewest startup tokens and no significant conformance drop; `promote`, run in a south worktree and landed through `safe-push`, copies that candidate into `south:agents/operating-point.toml` unless it drops below the current point or the frozen anchor, with `--accept-drop REASON` to re-anchor. Arms, detectors and row fields are in `north policy-replay --help`.
