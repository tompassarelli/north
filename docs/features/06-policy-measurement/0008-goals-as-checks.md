- Goals as checks (north#641): each project (north, makgora, wisp) keeps `goals.toml` at its root, one `[[goal]]` per goal drawn from its README or AGENTS.md, with the line it comes from, an oracle command that prints one number, a `max` or `min` bound, and a class. A `contract` goal is never red: the after-landing run reads the landed tree twice and the landing's base, bisects the range to the first commit at which a goal turned red, and queues that commit's revert (`Goal-red:` trailer) ahead of the queue. A `debt` goal may be red up to its `ceiling` while its `owner` and `revisit` trigger stand in for the `Target-debt:` record (docs/rationale/targets.md). `north goals check [--root DIR] [PROJECT...]` runs every oracle side by side under 8 s each, prints value, source, oracle, class and verdict, and exits 1 on a red contract, a goal over its ceiling or an oracle with no number; `north land profile --metric landing-p50|landing-p90|verification-p50|verification-p90` measures landing times. The fleet tick tells the proxy `goals red (N): ...` when the red set changes and every 6 h while it stays red (`~/.local/state/north/goals/tick.json`).
