- Context audit: `north config context audit [--since 7d] [--json] [--session ID]` reads the Claude profile transcripts modified within the window and prints, per lead and worker session, injected characters and chars/4 tokens by source, grounding precision, and grounding injections whose prompt is a background task notification. It reads file by file and never prints message contents. The sources are startup from policy-gate measure, SKILL bodies, skill references, UserPromptSubmit grounding and other hook context; grounding precision is the share of named paths the session later read; an injection belongs to the prompt recorded after it, since a prompt hook's record is written before its prompt. Without `--json` it prints p50 and p90 per source for leads and workers and the top 10 injected skills.
