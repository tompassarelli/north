- Promises: a line of a session's report that names a time ahead of the report (`2:16 AM` in the laptop window's zone, or `2026-11-08T02:16Z`) and a command of two or more words in backticks is kept in the fleet root's `promises.jsonl` when the turn ends. Each host's fleet tick runs every due promise's command once, in the session's directory with a 60 s limit, records it in `promises-checked.jsonl`, and sends the proxy one urgent message naming the session, the line, the command and its exit when the command fails (north#838). A time before the report reads as a statement of the past and is never run.
