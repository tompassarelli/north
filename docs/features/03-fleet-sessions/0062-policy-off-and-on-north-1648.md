- Policy off and on (north#1648): `north policy off` takes north's policy away on this host and stops nothing. It moves north's instruction, skill and hook-script surfaces (`~/.claude/CLAUDE.md`, `~/.claude/skills`, `~/.claude/agents`, `~/.agents/*`, `~/.codex/AGENTS.md`, `~/.codex/skills`, `~/code/AGENTS.md`) into `$XDG_STATE_HOME/north/policy-off/`, takes north's hooks and worker-sandbox shell prefix out of `~/.claude/settings.json`, which every account profile links, and points the git hooks of every `~/code/*/main` checkout at an empty directory, so agent sessions started after it meet no north hooks, skills or instructions and the owner's own commits and pushes go as plain git. While its record exists, `north hook` answers nothing, which silences the hooks a system file still names. `north policy on` puts back exactly what it recorded and leaves anything changed since as it found it. Like `north fleet off`, it is `north-switch` and needs no north runtime; it deletes nothing and changes no login.
