- Two-rung routes (north#1233): `north fleet launch --route FAMILY[:EFFORT],FAMILY[:EFFORT]` of a Claude worker on a named issue starts the box on the first rung, a model family (haiku, sonnet or opus) and an optional effort, under a tier override, with a brief line telling it to end its turn `Not done` when its finish call's check fails, and to make the finish call even when it cannot finish; `small-first` names `haiku,opus`, and `opus:low,opus:medium` holds the model equal. `north finish` keeps every failed check's command, output and diff against origin in the lane's git directory and names that file on its failure line. When a first rung's completed turn ends with its last finish call's check failed, a verdict the finish call wrote rather than words of the report, the session watcher claims a once-only receipt and starts `north fleet launch --route after:NAME:RUNG` on the second rung from the project's main checkout. That second brief is the first brief, the attempt's report, its failed check and output, and its diff. An `after:` route never escalates, so a box starts at most twice without a person or the coordinator. Both launches write their route, model and session name to the dispatch launch record, which the tier loop joins to each session's usage in the run ledger.
