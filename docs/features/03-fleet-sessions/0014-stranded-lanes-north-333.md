- Stranded lanes (north#333): `north fleet stranded --json` lists this host's exited or parked sessions that the fleet parked, whose own builds still wait in capacity admission, or whose reply ended on a wait, with each worktree their report names and what it holds that origin/main lacks. Each `north fleet dispatch` run reads it from every host: a session whose lanes hold nothing new is forgotten, and any other keeps its issues and is revived once per report, with a turn naming its lanes, when its machine and account have room. `north ledger flow` lists each repository's stranded lanes, and `north ledger flow --stall-alarm` reminds the Fleet parent and the proxy while any remain.
