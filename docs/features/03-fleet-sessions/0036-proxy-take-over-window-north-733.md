- Proxy take-over window (north#733): when `north fleet launch --role proxy --take-over` or the fleet tick's hand-over gives the proxy role to a new session on a host with a live graphical session, north opens it in a terminal window titled `north NAME` that runs `north fleet interactive NAME`, so the new proxy is on screen at once. The compositor spawns the window, so it is no child of north; the desktop is one port (`Opener`) with niri and ghostty as its adapter, and it finds niri's socket in the runtime directory when `NIRI_SOCKET` is unset. A host with no niri socket (gex45, cloud) or a proxy on another machine opens nothing, and the launch still succeeds with a stderr line saying why. A window still open on the conversation of a proxy that a take-over archived no longer counts as Tom's directing window, so the new proxy messages and launches at once; a window on any other conversation still holds direction until it has been idle for 30 minutes.
