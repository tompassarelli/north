- Fetch and fleet in one call (north#112): `north fetch-fleet [VIEW [ARGS...]]` runs `git fetch` in the current directory, then `north fleet VIEW ARGS` (`list` when no view is named), then `git fetch` again, stopping at the first step that fails and exiting with its code. It replaces the three calls `git fetch`, `north fleet` and `git fetch` that `north tool-mine` found 64 sessions making in a row within 7 days.
