- Fleet gates: each fleet tick publishes this host's open decision gates to the store's `fleet_gates` table and caches it, so `north gate list` and the issue-gate guard behind `north fleet launch` and dispatch see the gates every host holds, answerable as `HOST:ID`. `north gate answer HOST:ID N` spools the answer for the asking session's host to apply once on its tick (north#184), and `north gate open` for a session another host runs spools a GATE row that host opens as its own gate (north#416). `north gate --help` gives the forms.
