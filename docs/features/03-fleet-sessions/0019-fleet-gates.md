- Fleet gates: each fleet tick publishes this host's open decision gates to the store's `fleet_gates` table and caches it, so `north gate list` and the issue-gate guard behind `north fleet launch` and dispatch see the gates every host holds, answerable as `HOST:ID`. `north gate answer HOST:ID N` spools the answer for the asking session's host to apply once on its tick (north#184), and `north gate open` for a session another host runs spools a GATE row that host opens as its own gate (north#416). `north gate open --issue OWNER/REPO#N --box TEXT` holds only launches whose `Item:` line carries TEXT, so one box of an umbrella issue does not hold its others (north#568). `north gate --help` gives the forms.
- Ask-once gates and multi-box issues: a gate whose question or options name a word from an `ask_once_*` class in `harness/defaults.toml` (cost, accounts, credentials or access, making something public, deleting valuable data, core direction and dependencies) is refused with `--default` or `--default-after`, opens without them, lists with a null default and waits for Tom's answer, as does an `AskUserQuestion` gate of such a question; every other gate still needs both. `north gate open --issue` without `--box` is refused when the issue has more than one open box, so a gate holds a whole issue only when it has a single open box (north#670).
