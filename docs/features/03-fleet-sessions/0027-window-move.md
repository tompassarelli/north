- Window move (north#636): `north proxy move [--to ACCOUNT] [--auto] [--dry-run]` moves the coordinator's open terminal window to another account when its account's outlook runs short, or to the account named with `--to`, resuming the same conversation under the target profile and closing the old window only after the new one runs. A failure before that last step leaves the old window running as it was. The fleet tick runs `--auto`, and `--dry-run` prints the plan without moving anything.
