- Window move: `north proxy move [--to ACCOUNT] [--auto] [--dry-run]` finds Tom's one interactive `claude` window on a terminal and, when its account's outlook is under 45 minutes (or out), or when `--to` names an account with week headroom, moves it to the account with the most week headroom whose own outlook is not under 45 minutes. It copies the session's transcript, subagent files, file history and session environment into the target profile, opens a replacement ghostty window running `claude-ACCOUNT --resume SESSION` with the old window's flags, waits until that process runs under the target profile's `CLAUDE_CONFIG_DIR` with the session loaded, and only then (still at the end of a turn) stops the old daemon-hosted session, hangs up the old window's shell and puts the new window in the old one's workspace and column with focus restored. A failure before that point closes only the replacement and leaves the old window as it was. The fleet tick runs it with `--auto`, which does nothing while the turn is running, until the next tick (north#636).
