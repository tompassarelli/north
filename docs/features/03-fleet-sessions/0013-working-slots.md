- Working slots: a host slot and the working target count only sessions `starting` or `working`; an idle session, or one parked on a registered run, keeps its issue and claims but no slot. `north fleet wait RUN` registers a run (`job:`, `farm:`, `branch:` or `capture:`) and parks the session when its turn ends; the fleet tick, or `north fleet waits` by hand, revives it with the run's result once the run is over. A run the session detached from its CLI is found in its session scope and registered as a `pid:` wait on its own, surviving revivals until it ends. An idle session with nothing to wait on parks at its idle limit and its next message revives it.
