- Launch hosts: a `[hosts.NAME]` with an `ssh` destination takes a fresh launch, and is a fall-through target when the host a launch named is saturated, only when it sets `launches = true`; `HOST skipped: not a launch host` names any other. A fall-through note reads `gex45 saturated; placed on ccx33 (why)`, and when no launch host is open the launch is held with the saturated host's reason.
