- Dispatch pause and queued launches (north#960): `north fleet dispatch pause --reason TEXT` records the proxy's pause under `~/.local/state/north/dispatch-paused` and stops `north-dispatch.timer`; while the record stands, `north fleet dispatch` launches and revives nothing, the code-health review tick, the watch-review and incident-retro launches and the skill prune start no fleet session, and each launch the laptop's job queue runs goes through `north fleet dispatch queued --by HOST --item REPO#N [--box TEXT] -- WORDS`, which prints `dropped REF: reason` and starts nothing when dispatch is paused here or on the host that queued it, the issue is closed, or the named box is ticked. `north fleet dispatch resume` removes the record and starts the timer, `north fleet dispatch paused` prints the reason with exit 0 or exits 1, the south dispatch timer carries `ConditionPathExists=!%h/.local/state/north/dispatch-paused` so a deploy that starts it under a pause leaves it inactive, and `north health` alarms a host whose timer runs under a recorded pause.
