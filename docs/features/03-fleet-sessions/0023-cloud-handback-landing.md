- Cloud handback landing: `north cloud land EVENTS` applies the latest patch handback in a cloud session's transcript with `git am --3way` in a fresh `worktrees/cloud-SESSION` lane off origin/main, folds it into one commit without session trailers, runs `north land checks` on it and enqueues it with `safe-push --to main`, printing `Done: queued`, or stops with the reason and the lane path and queues nothing; a handback already queued is a no-op. `north cloud wait` runs it when the finished session's transcript holds a handback, so a cloud worker's patch lands without a lead.
