- Fleet off and on (north#1648): `north fleet off` stops all fleet activity on every host at once and changes no policy. It freezes landing on each host, stops the units that start work (dispatch, the fleet tick and every other fleet timer), waits up to ten minutes for working sessions to finish their step, then stops every fleet session and unit and kills what still runs at the deadline; `--force` kills them at once. It records what it stopped in `$XDG_STATE_HOME/north/fleet-off`, parks the stopped sessions in the cached fleet table so `north fleet tree` shows none working, and returns when nothing of the fleet runs. `north fleet on` starts exactly the recorded units, leaves a timer's service to its timer, names transient units (sessions among them) that cannot come back, and lifts the freeze it placed. Both are `north-switch`, a program of its own that needs no north runtime: the host configuration installs it, as `north` too, handing every other command straight to the runtime at `~/.local/state/north/current/north`, and the `north` shim hands it these two words before loading the runtime. Which hosts it reaches and which user units are the fleet's come from `$XDG_CONFIG_HOME/north/fleet-units` (`host NAME`, `unit GLOB`, `keep GLOB`), which the host configuration writes; without it, `north-*` and `fleet-*` on this host are stopped and the credential broker is kept.
