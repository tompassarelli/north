- Page-flood backstop (north#1048): the fleet store's send path bounds what reaches the coordinator. A service names a standing condition with `north fleet send --from service:UNIT --key CONDITION`, and the store delivers one message per key per episode; `north fleet held` prints the held repeats. A service past three messages to the coordinator in ten minutes is folded into one line carrying the count and recorded as a `page-flood` incident (`north ledger incident report`), and service messages that read the same once their unit or path is taken out go as one follow-up. Messages from sessions, from the operator and gate messages pass unchanged.
