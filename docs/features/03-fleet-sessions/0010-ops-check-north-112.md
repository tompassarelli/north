- Ops check (north#112): `north ops check`, on a five-minute timer on the always-on host and on one other host as its dead-man, turns each expectation in `north-data/expectations.toml` (a measure, a threshold, a window, an owner and the fix it should become) into one phone push through the publish-only `ntfy-publisher-token` at `NEXUS_ALERT_NTFY_URL` (falling back to `nexus-alert` where a host has no token or no URL) and one message to the `[notify] coordinator` session when it breaches, and one `cleared` when it clears; a standing breach stays quiet. `--dry-run` prints every expectation's state and sends nothing, and `--synthetic`, on a weekly timer, proves both channels still deliver and writes `ops/drill.json` with the time only when both arrived, so the `nexus-drill` expectation read on the dead-man host turns red when the weekly drill never ran or one channel missed.
