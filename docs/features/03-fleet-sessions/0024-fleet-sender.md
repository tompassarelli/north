- Fleet sender: every message row carries a required `Sender` (`tom`, `session:NAME` or `service:UNIT`, on the wire as that text) and no send path defaults it. The fleet TUI composer sends as `tom`, which reaches the session unprefixed on any host; a session sends as itself (`[from NAME]`); a timer or daemon sends as `service:UNIT` (`[from service:UNIT]`), and fleet machinery (parent notices, wait settlements) as `service:north-fleet`. `north fleet send [--now] [--from service:UNIT] NAME TEXT...` and `north fleet ask NAME [--from service:UNIT] QUESTION...` outside a fleet session without `--from` are refused, `--from tom` is refused everywhere, and a source test in `fleet::sender_tests` fails any Rust or `bin/` shell-out to `north fleet send` that omits `--from` (north#112, box W1).
