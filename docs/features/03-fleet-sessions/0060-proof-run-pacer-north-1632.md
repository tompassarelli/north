- Proof-run pacer (north#1632): `north proof-run --repo OWNER/REPO` opens one issue per stage on a scratch repository and writes a stand-in box onto it every 3600/RATE seconds (default stages 30, 60, 120 and 210 an hour), so dispatch staffs each with a stand-in worker. Each minute it counts the `si*` stand-in landings in `north land profile --repo NAME` and stops with exit 2 once a box written over 5 minutes ago has stayed unlanded for 5 minutes. `--dies-at RATE --dies N` marks the first N boxes of that stage `dies once mid-lane`, whose first stand-in exits after making its lane, so recovery restarts the box.
