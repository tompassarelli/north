- Proof-run pacer (north#1632): `north proof-run print --start TIME --issues N --dir DIRECTORY` writes N files, each an issue title on its first line and its body after, holding the run's stand-in boxes dealt round-robin in time order (default stages 30, 60, 120 an hour for 10 minutes each, then 210 an hour for 70), each stamped `(not before TIME)` at its stage's rate, for an operator to file before the run; the ramp lives in the stamps dispatch honours and the run writes nothing to GitHub. `--dies-at RATE --dies N` marks the first N boxes of that stage `dies once mid-lane`, whose first stand-in exits after making its lane, so recovery restarts the box. `north proof-run watch --start TIME` reads `north land profile --repo autoland-scratch` each minute, prints the boxes opened, landed and due, and stops with exit 2 once a box due over 5 minutes ago has stayed unlanded for 5 minutes.
