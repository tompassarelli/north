The reasons are recorded on the session and shown in `north fleet list`. `--test` sessions skip the gate. A launch claims, before it starts, every issue it holds (`--task REF`, else all those the first `Item:` line names up to a word such as `follows` or `see`, in the prompt or the brief it points at; the first is the session's task and `fleet list --json` shows all as `tasks`), refusing on a live claim and taking one a stopped session left, and releases them when the session ends or fails to start. A `--task REF` or `Item:` launch is refused while a running fleet session on this host, any other host (over ssh, or the laptop's copied list) or a dispatch launch of the last two hours already holds REF, unless `--force-dup "REASON"`, which is recorded as `dup: REASON`.
