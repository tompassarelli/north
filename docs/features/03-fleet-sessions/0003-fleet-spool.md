- Fleet spool: every `north fleet send`, parent notice and `ask` first writes a MESSAGE row to this host's fleet spool. A recipient on this host gets it at once through `hand_in`, the one path that delivers a row into a session, which journals each row id in the session's `delivered` directory so a row is delivered once. A name only in the cached fleet table is left for the fleet ticks to carry to its host, and a name in neither fails at once. The ticks deliver MESSAGE, GATE, GATE-ANSWER and JOB-EXIT rows by row id, and a tick that pulls a far machine delivers to that machine's sessions over ssh. `north fleet spool --help` lists the machine-side verbs. A session cannot be named `spool` (north#429).
