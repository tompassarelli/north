- Fleet state follows XDG (north#964): every fleet path — the session registry, the land queue it reads, standing orders, phases and the graph — lives under `$XDG_STATE_HOME/north` when `XDG_STATE_HOME` is an absolute path, else `~/.local/state/north`, alongside the lander's queue; account profiles stay at `~/.local/state/north/profiles`. A run with `NORTH_TEST_ROOT` set refuses any fleet or lander state outside that root, and a `--test` fleet launch refuses when the root is unset.
