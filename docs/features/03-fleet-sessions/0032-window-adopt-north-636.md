A message to the name, a backlog the old holder never took included (the window takes every message sent since the old holder began), goes into the window as one turn over its Claude Code session inbox (the socket and peer key its `sessions/PID.json` names), and the window's `north fleet send` signs as NAME. While the window lives the name reads `idle` and a second proxy launch is refused; revive, relaunch and the fleet tick start no host under the name, so the archived holder never wakes again. Adopting from another window ends the first window's hold; a closed window reads `exited` and a message to it fails naming the fix.
