- Drafts (north#1240): a draft is the change a qualifying open box would get, computed on the small model before the box is launched and kept as one unpushed commit in a lane made with `north lane new --draft`. `north fleet dispatch --draft REPO#N...` starts one for each named issue's ready box that has a test command and no placed worker, and `north fleet drafts` lists each draft's age, check result, tokens, cost and whether main has moved under its files. When dispatch launches a box whose latest draft passed, it lands the draft instead through `north lane land-draft` (rebase onto current main, the check again, safe-push) and prints `landed ... from a candidate`; a draft that failed, passed without its change or did not land on current main goes into the launched worker's brief as text with its diff (north#1233).
