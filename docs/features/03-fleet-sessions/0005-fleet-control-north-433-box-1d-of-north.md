- Fleet control (north#433, box 1d of north#429): `north fleet forget`, `stop` and `interrupt` of a name this registry lacks but the cached `fleet_sessions` table names write one CONTROL row (the verb in its text) to the spool and print `spooled CONTROL row ID`; a name in neither fails with `no session named NAME`. When the cached row's host has no `[hosts.NAME]` table in the orchestration config, no host will tick for it, so the verb instead retires that host's rows from `fleet_sessions` through `north fleet row retire` on the ledger host and drops the name from this host's cache at once, printing `retired NAME at once` (north#794). The tick on the host that holds the session fetches CONTROL rows for its stopped sessions as well as its running ones (a stopped session still receives no MESSAGE), and applies each once: `stop` and `interrupt` are journaled by row id in the session's `delivered` directory, and `forget` needs no journal because the session leaves the registry. `show` stays local-or-error.
