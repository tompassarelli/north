- Dispatch: `north dispatch`, run on Nexus by a timer (south `modules/north-dispatch.nix`), keeps free worker slots busy. It prints each host's cap and running sessions, each account as open or out, the free slots per host and account, and every open issue in the staffed repositories with why it is or is not ready: a label holding it for Tom, a live session, gate, claim or recent launch on it, an open predecessor, or a box gated `(not before TIME)`. Each ready box gets a generated brief and goes, in project priority order, to the cloud lane when it is code-only in an Autoland repository, else to the host that serves its needs and would start it soonest, on the open account that ranks first by pace. Attempts are logged in `~/.local/state/agents/dispatch/launches.jsonl`. An item tried twice without progress is left to the proxy (a session no registry lists spends no try), issues with no box go once a day to the triage lead or else the proxy, ready work with nothing launched raises one `nexus-alert`, and a launch queued behind an in-flight lane is held, not failed. `--dry-run` launches nothing.
