- Dispatch (north#1020): `north fleet dispatch`, run by the fleet tick on the host `[placement] dispatch_host` names, keeps free worker slots busy. It reads every open issue of the staffed repositories, says why each is or is not ready, and launches one worker per open, unheld box with a brief whose `Box:` line names the box and whose Done when is that box; a box whose paths overlap a running box waits, so two workers never edit one module at once. Each brief goes to the cloud lane when it is code-only in an Autoland repository, else to the host that serves its needs and would start it soonest, on the open account that ranks first by pace. A host or local need a worker records with `north fleet need HOST REASON` keeps its box off hosts that lack it; an item tried twice without progress is left to the coordinator, and a pause recorded for dispatch holds the whole run. `--dry-run` launches nothing and prints the plan, and `--draft REPO#N...` computes drafts ([drafts](features/03-fleet-sessions/0053-drafts-north-1240.md)).
