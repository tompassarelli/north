- Dispatch: `north dispatch`, run on Nexus by a timer (south `modules/north-dispatch.nix`), keeps free worker slots busy. It prints each host's cap and running sessions, each account as open or out, and the free slots per host and account, then every open issue in the staffed repositories with why it is or is not ready: a label holding it for Tom, a live session, gate, claim or recent launch on it, an open predecessor, or a Done-when box gated `(not before TIME)`. Each ready box gets a generated brief and goes, in project priority order, to the cloud lane when it is code-only in an Autoland repository, else to the host that serves its needs and would start it soonest (`dispatch_heavy_memory_mib`, `dispatch_agent_memory_mib`), on the open account that ranks first by pace (`reservation_fallback_points`). Attempts are logged in `~/.local/state/agents/dispatch/launches.jsonl`; an item tried twice without progress is left to the proxy, issues with no box go to the triage lead, and ready work with nothing launched raises one `nexus-alert`. `--dry-run` launches nothing.
