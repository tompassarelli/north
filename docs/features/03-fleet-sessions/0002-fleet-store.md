- Fleet store: `north fleet row put` reads one fleet row or an array of them as JSON on stdin and commits them to the threads ledger in one transaction, once per row id, printing `committed ID` per row; where this machine does not hold the ledger it forwards the rows over the threads ssh remote and answers the remote exit code. The ledger also holds `fleet_sessions`, one row per session name with the provider, account, cwd, parent, placement, machine, tasks and conversation `fleet list` shows, which a launch claims only while no session of that name is live fleet-wide (north#429). A host lists another host's session with its conversation, so the run ledger on the machine that holds a placed session's transcript records that session's run (north#255).
