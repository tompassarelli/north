- Fleet tick (north#1020): `north fleet tick`, run on each fleet host by a timer, makes one `north fleet row exchange` with the ledger host, publishes this host's registry and delivers each row addressed to its sessions once, reviving a parked recipient. On the dispatch host it also runs `north fleet dispatch` when the last run is five minutes old and dispatch is not paused, so the review-and-land loop needs no coordinator step. Each stage that calls another host has its own time budget; one that overruns is named in a `deferred` line and its rows wait for the next tick. A host marked `pulls_spool` runs only the probes on its own registry, and a host whose `[hosts.NAME]` entry sets `fleet_reports = false` skips the goals, scoreboard and corrections probes.
