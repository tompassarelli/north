- Fleet tick: `north fleet tick`, run on each fleet host by the `fleet-tick` timer, makes one `north fleet row exchange` with the ledger host. It commits this host's spool and the spools it takes from the far machines whose CLIs it runs (`north fleet spool take`, dropping only the ids the exchange committed), publishes this host's registry into `fleet_sessions` and caches the whole table, and fetches the rows addressed to its sessions, delivering each through `hand_in` once by row id and reviving a parked recipient. A failed pull is reported per machine without stopping the others, and a row the store refuses is set aside on its machine with a notice. A prompt's uuid derives from its row id, so a tick killed mid-delivery redelivers at most once (north#429).
