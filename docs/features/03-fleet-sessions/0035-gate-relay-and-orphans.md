- Gate relay and orphans: `north gate answer ID N --relayed-from-turn CONVO_ID` lets a fleet session close a gate for the owner when that convo-store turn is a human turn by the owner in the session's own conversation, typed after the gate opened, whose text names option N; any other turn is refused with the reason, and the closure records the owner as answerer with the turn id. A gate whose asking session no longer exists and whose issue (`--issue`, else each `repo#N` its question names) is closed closes itself as `orphaned`, recorded and delivered to nobody, the next time any `north fleet` or `north gate` command runs. `north gate withdraw ID --reason TEXT` closes a gate opened in error, for the owner, the coordinator or the gate's asking session, recording the reason as its answer and the withdrawer as `withdrawn`; the gate leaves `north gate digest`, and each withdrawn ask-once gate appears there once with who withdrew it and why; no option is chosen so an ask-once gate approves nothing, and the asking session is told unless it withdrew the gate itself.
