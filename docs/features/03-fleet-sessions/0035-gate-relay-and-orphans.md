- Gate relay and orphans: `north gate answer ID N --relayed-from-turn CONVO_ID` lets a fleet session close a gate for the owner when that convo-store turn is a human turn by the owner in the session's own conversation, typed after the gate opened, whose text names option N; any other turn is refused with the reason, and the closure records the owner as answerer with the turn id. A gate whose asking session no longer exists and whose issue (`--issue`, else each `repo#N` its question names) is closed closes itself as `orphaned`, recorded and delivered to nobody, the next time any `north fleet` or `north gate` command runs.
