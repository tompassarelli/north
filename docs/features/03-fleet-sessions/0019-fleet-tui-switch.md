- Fleet TUI switch: in the composer `Esc` interrupts the selected session when it is working (and moves focus to the list otherwise; `Ctrl+C` still interrupts), and `/model NAME` and `/effort LEVEL` are run by the TUI instead of being sent to the model: they stop the selected session and restart it on the same conversation through `north fleet relaunch NAME [--model M] [--effort LEVEL]`, which checks the model and effort as a launch does before it stops anything; with no argument they show the current value and the valid choices. `north fleet interactive NAME` hands a session to Claude Code's own UI: it stops the fleet host, waits until it has exited, marks the record stopped and execs `claude --resume CONVERSATION` in the session's directory under the account's credential and environment; `north fleet revive NAME` takes the same conversation back into the fleet and, like `relaunch` and `interactive`, refuses while an interactive `claude` still holds that conversation.
