- Fleet TUI switch: in the composer `Esc` interrupts the selected session when it is working (and moves focus to the list otherwise; `Ctrl+C` still interrupts), and `/model NAME` and `/effort LEVEL` are run by the TUI instead of being sent to the model: they stop the selected session and restart it on the same conversation through `north fleet relaunch NAME [--model M] [--effort LEVEL]`, which checks the model and effort as a launch does before it stops anything, and starts a fresh conversation whose first turn is `Follows:` and the last report when the new model belongs to another family than the old one, since it cannot read the thinking the old conversation holds; with no argument they show the current value and the valid choices. `north fleet interactive NAME` hands a session to Claude Code's own UI: it stops the fleet host, waits until it has exited, marks the record stopped and execs `claude --resume CONVERSATION` in the session's directory under the account's credential and environment; `north fleet revive NAME` takes the same conversation back into the fleet and, like `relaunch` and `interactive`, refuses while an interactive `claude` still holds that conversation. A relaunch, `north fleet revive` or a revive sent from another host hands a session whose turn it cut short, or whose host exited mid-turn, a turn that tells it to carry on, since the restarted CLI otherwise runs nothing and is parked at its idle limit. A session whose host exits mid-turn without being stopped is revived by its watchdog on the same conversation with that turn; a second such exit within the hour of the revive is reported to its parent as `host … exited mid-task again within the hour of its revive` instead, so a crashing session cannot loop (north#769).
