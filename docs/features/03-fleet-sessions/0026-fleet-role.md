- Fleet role: every session record carries `role`, set by `north fleet launch`: `--role proxy|lead|worker` when given, else `worker` for a launch with a task (`--task` or an `Item:` line) and `lead` for any other. The host exports it as `NORTH_FLEET_ROLE` beside `NORTH_FLEET_SESSION`, and `fleet list --json` shows it. A proxy is named `proxy` and has no parent; while one proxy session is live a second proxy launch is refused unless it passes `--take-over` under the live proxy's name. The ledger's session role and the lead-timer guard read the field; a record written before roles infers it from its name, parent and task (north#112).
