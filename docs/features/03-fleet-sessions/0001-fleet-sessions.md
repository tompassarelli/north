- Fleet sessions: `north fleet launch` starts a session and first registers its row in the fleet store's `fleet_sessions` table on the ledger host, so one live session holds a name fleet-wide (`--take-over` replaces the row), and the launch refuses with the reason when the store refuses the name or does not answer. `north fleet send` and `ask` message a session, `north fleet tree` shows parent links and `north fleet revive` restarts one; `north fleet list` and `tree` read the copy of the table the fleet tick caches, so they show every host's sessions without waiting on the ledger host. A message to a session on another host travels through the fleet spool. A host marked `pulls_spool` in its `[hosts.NAME]` entry only runs the CLIs other hosts place on it and refuses launches. `north fleet --help` gives every subcommand and flag.
