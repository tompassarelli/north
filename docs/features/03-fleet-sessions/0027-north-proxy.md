- North proxy: `north proxy` opens north's fleet TUI on the fleet session `proxy`, attaching when it is live, reviving it when it is parked or stopped, and otherwise launching it through `north fleet launch`'s own account routing with `--role proxy --parent none` in `~/code/north/main`. The Claude host passes `--agent proxy` to a proxy session, so `harness/claude/agents/proxy.md` is its agent definition from the first turn. The first launch stops and archives the proxy records written before roles (`proxy`, `proxy-*`) and any recorded proxy under another name, and hands the new proxy one line saying how many messages to them were waiting, from which senders and how old the oldest is, instead of replaying them. `north proxy --interactive` is `north fleet interactive proxy`: it stops the fleet proxy and waits for its host to end before it execs `claude --resume` on the same conversation, and the proxy is not revived while that UI holds it. A running proxy is a candidate of the fleet tick's hand-over without a lane: when its account is out it is taken over under its name onto an account with headroom, keeping role proxy and resuming its conversation (copied into the new account's config directory when the two differ), which passes the one-live-proxy refusal because a take-over moves only the name it launches under (north#112).
