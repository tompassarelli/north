- North proxy: `north proxy` opens north's fleet TUI on the fleet session `proxy`, attaching when it is live, reviving it when it is parked or stopped, and otherwise launching it through `north fleet launch`'s own account routing with `--role proxy`, so `harness/claude/agents/proxy.md` is its agent definition from the first turn. `north proxy --interactive` stops the fleet proxy and resumes the same conversation in `claude`, and the proxy is not revived while that UI holds it. When the proxy's account is out, the fleet tick takes it over under its name onto an account with headroom and resumes its conversation, so there is always exactly one live proxy (north#112).
