- Claim holder reads (north#562): `threads holder REPO#N ...` and `threads holder --owner NAME ...` print the claim rows, as JSON `{item, owner}`, on those items or held by those owners, through one lookup per item on the claims table's item key or per owner, and read neither GitHub nor any fleet, so a read stays cheap on a loaded ledger host. `north fleet launch`, `--test` included, asks the ledger only who holds the items it names and clears any claim an exited session left on them; every other mutating `north fleet` verb leaves exited sessions' claims to the exited-claims sweep. Neither reads `threads list --json --all`. A launch whose holder read does not answer within 2 s is refused before it registers anything, naming the read that timed out, so `north fleet list` shows no half-made session.
