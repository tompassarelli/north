- Fleet reaper (north#636): the fleet tick's last probe retires an idle or parked session that nothing would wake once its parent has taken its final report, or when it has been quiet past `fleet_stale_hours`. Retiring gives up the session's claims, archives its directory and frees a finished remote lane, and a message sent to a retired name goes to its nearest live ancestor. `north fleet reap [--dry-run]` prints each verdict.
