- Fleet reaper (north#636): the fleet tick's last probe, `probes.settle.reap`, stalest first and within 5 s per tick, retires an idle or parked session (not the proxy, an adopted window or a verify-north session) that nothing would wake (no registered wait, open gate, queued land ticket, live child, job lease or running process in its scope) when its newest final report, with no new instruction after it, was taken by its parent, as a turn or held in its digest (north#1054), and opens `Done:` with every commit it names on origin/main, or `Not done:`, `Blocked:` or `Split:` with a `Stop:` line while its CLI runs no background work, read over ssh on the machine a placed session runs on (north#776); or when it has been quiet past `fleet_stale_hours`. Retiring gives up every claim the session holds in the threads ledger, and a lane the lander landed after a `Done:` report no longer holds the session, while a refused lane does until the session is woken (north#1054). Retiring writes `retired.json` (why, when, last reply) and moves the session directory and transcript under `.archive` with `ended: retired`; it frees a remote session's lane, read the same way as a forgotten one's, over ssh with `north lane remove`, which removes a finished worktree and target and keeps one still holding unlanded, uncommitted, locked or queued work (a kept lane ends the transient `north-lane-free-*` unit normally and is appended with its machine and reason to `.kept-lanes.tsv`, which `north fleet reap` prints for the last 24 h, while an ssh failure or any other exit still fails the unit; north#1202), and touches no local worktree. A message or row to a retired name goes to its nearest live ancestor, else the proxy, as one turn, never reviving it, and is logged in `.dead-letters.jsonl`. A service's message (`north fleet send --from service:UNIT`) to the lander's owning session (`land_notice::OWNER`) while no live or parked session holds that name on any host goes to the proxy prefixed `(for NAME, not live)` and is logged there once (north#902). `north fleet reap --dry-run` prints each verdict; each tick tells the graph every idle or parked session's verdict and the dead letters of the last day as writer `fleet`, the `fleet-retire` loop's facts (north#882).
