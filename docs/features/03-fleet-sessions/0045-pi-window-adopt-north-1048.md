- Pi window adopt (north#1048): `north fleet adopt --name proxy` run inside a Pi session binds the name to `PI_SESSION_ID`, records the window's Pi process, and installs the `north-fleet.ts` extension so a later Pi start or `/reload` loads it; the registry under `<state>/north/pi-windows` makes dispatch and the fleet tick count the name live while its Pi process runs, and a report to the name reaches the session as a user message over `<state>/north/pi-sessions/<pid>.sock`, queued as a follow-up while the session streams. A Pi window whose process is gone reads `exited`, and a second proxy launch is refused as for a Claude window.
