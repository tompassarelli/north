- Repeated unblocks (north#1577): the coordinator's manual unblocks are kept by class in `~/.local/state/north/unblocks.jsonl`: `north runtime trip clear COMMIT --why TEXT` by the failing tests the trip names, the coordinator's `north fleet launch` of a task whose last launch was refused by that refusal's words (digits and names folded away). The second of one class within 24 h is refused unless it names an open issue with an assignee or an `Owner:` line that fixes the class: `--issue REPO#N` on the verbs. Each hour the fleet tick wakes the coordinator with the top harness-loss classes of the last hour, which `north work --since 1h` prints under Harness losses with the issue that owns each (`harness_loss_owners`, or the last `north work own CLASS --issue REPO#N`, until the GitHub mirror records it closed). Class rule: a trip clear's class is the sorted set of `case in name` its trip names, so two trip clears are one class only when they name the same cases; the test that refuses a second clear of one class is `repeat_unblock_a_second_trip_clear_of_one_failing_test_names_an_open_owned_issue` in `src/cli/repeat_unblock_tests.rs`; the hourly review and its held turn are pinned by `hourly_class_review_wakes_the_coordinator_once_an_hour_and_holds_its_turn_while_a_repeated_class_has_no_owner` in `src/cli/fleet/class_review_tests.rs`.
