- Hand stops (north#1136): `north holds list [--json]` lists every stop a person or the coordinator set by hand, on this host and on every host it ships runtimes to. Each host answers `north holds list --here --json` over ssh, and one that does not answer is named. The list covers the dispatch pause, each issue a session holds beside its own task (`north fleet hold`), the laptop's drain or close word when a person or session set it, the stable-pin hold, and any lock in `~/.local/state/north` that a process other than north holds, such as a unit holding `records-mirror.lock` to stop the records mirror, named by its unit, its description and its start. Each line names who set it, why, since when and what lifts it; a stop whose lift came 10 minutes ago (its expiry passed, its cause check passes, or its session ended) or that names nothing that lifts it once it has stood 10 minutes is marked red. The monitor's health section shows the same list every 30 s with the red ones as alerts.
