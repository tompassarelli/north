- Hand stops (north#1136): `north holds list [--json]` lists every stop set by hand on this host and on every host it ships runtimes to. Each host answers `north holds list --here --json` over ssh, and one that does not answer is named. The list covers the stable-pin hold and any lock in `~/.local/state/north` that a process other than north holds, such as a unit holding `records-mirror.lock` to stop the records mirror, named by its unit, its description and its start. Each line names who set it, why, since when and what lifts it; a stop whose lift came 10 minutes ago or that names nothing that lifts it once it has stood 10 minutes is marked red.
