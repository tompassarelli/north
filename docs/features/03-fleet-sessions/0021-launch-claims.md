- Launch claims (north#855): `north fleet launch` claims every issue its session holds before it starts (`--task REF`, else the issues the brief's first `Item:` line names) and releases them when the session ends or fails to start; `north fleet list --json` shows them as `tasks`. With `--box TEXT`, or a `Box:` line in the brief, the claim covers that one box: a second launch on another box of the same issue is admitted, a second launch on the same box is refused. A session that files an issue holds it with `north fleet hold REPO#N`, so dispatch never staffs a second worker on it, and `north fleet hold --release REPO#N` gives it back.
