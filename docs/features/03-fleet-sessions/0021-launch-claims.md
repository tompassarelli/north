- Launch claims: `north fleet launch` claims every issue its session holds before it starts (`--task REF`, else the issues the brief's first `Item:` line names), refusing on a live claim and taking one a stopped session left, and releases them when the session ends or fails to start; `north fleet list --json` shows them as `tasks`.
- Filed claims: when a fleet session files the issue its brief asks it to file first (an `Item:` naming a new issue), the PostToolUse filing hook claims the new issue for that session as soon as `gh issue create` returns its URL, so north dispatch never staffs a second session on it; a blocker it files (a `Blocks:` line) stays unclaimed for dispatch to staff. Before this, dispatch staffed north#736, north#737 and north#739 beside the sessions that had just filed them.
