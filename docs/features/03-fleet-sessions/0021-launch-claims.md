- Launch claims: `north fleet launch` claims every issue its session holds before it starts (`--task REF`, else the issues the brief's first `Item:` line names), refusing on a live claim and taking one a stopped session left, and releases them when the session ends or fails to start; `north fleet list --json` shows them as `tasks`. A launch whose issue a running session on any host or a recent dispatch launch already holds is refused unless `--force-dup "REASON"`, recorded on the session as `dup: REASON`.
