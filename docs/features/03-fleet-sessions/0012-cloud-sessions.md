- Cloud sessions: `north cloud launch REPO SLUG BRIEF` refreshes a depth-1 full-tree checkout of the public repository under `/tmp/cloud/src/REPO`, marks it trusted in the login's `~/.claude.json` just before launching, and starts BRIEF plus the cloud safety line and the steps that push `claude/land-SLUG` through `claude --cloud` from it, printing the session, the branch and the checkout. `north cloud list | events ID OUT | sweep DIR | send ID FILE | wait ID OUT [--after UUID] [--timeout SECS]` reads, messages, waits on and sweeps the Anthropic cloud sessions of the host's `~/.claude` login through `curl`, with the token on curl's stdin config, never in argv ([cloud.md](../harness/skills/workers/references/cloud.md)). `send` posts FILE as a user message to an idle session and prints the HTTP status and the message uuid; `wait` writes the transcript once the session is idle and its newest turn event ends the turn, after that uuid when `--after` is given, and exits 1 on timeout; `sweep` archives only `anthropic_cloud` sessions in `requires_action`, never bridges.
