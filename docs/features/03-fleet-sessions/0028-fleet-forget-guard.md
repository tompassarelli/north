- Fleet forget guard (north#360): `north fleet forget NAME` refuses while a waiting ticket in any `~/.local/state/north/land-queue/<key>/` (not its `done/`, `withdrawn/` or `quarantine/`) names the session or has the session's worktree as its lane, naming each blocking ticket's file and branch, because the lander tells that session the lane's verdict and a forgotten one cannot hear it. `--force REASON` forgets it anyway and prints each overridden ticket with the reason; the fleet TUI's `^D` forget takes the same refusal. A session with a parent still in the fleet, or a successor named with `--to NAME`, is not refused: its waiting tickets are re-pointed at that heir, who is told each branch and its unlanded worktree (north#941), and the reaper's retirement of a session does the same and refuses when no heir exists.
