- Refused land branches: `north flow` reads the `autoland` commit status of every unlanded `claude/land-*` tip in a repository whose Autoland posts one (wisp and makgora) and lists a failed tip under `refused` with its pusher, the refusal and the run link. While that pusher is no live Fleet session, `north flow --stall-alarm` reminds the Fleet parent and the proxy until the branch is fixed or withdrawn; a live pusher hears the refusal from its own safe-push wait.
