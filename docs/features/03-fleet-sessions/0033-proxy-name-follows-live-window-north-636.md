- Proxy name follows a live window (north#636): no one runs `north fleet adopt` for the proxy. Every interactive window's SessionStart hook runs `north fleet adopt --name proxy --if-free`, which binds the name to that window only when no live session holds it (a parked or exited holder does not hold it) and prints nothing otherwise; fleet sessions and subagents never run it. A message to `proxy` whose holder is dead is delivered to the newest live interactive window (`entrypoint` `cli` in `sessions/PID.json`) that no other session holds, which takes the name over, so a message never revives the dead holder. Adoption leaves a `host.sock` directory in the name's session directory, so a session host from an older runtime fails at its socket bind before it starts the provider and cannot un-adopt a live window, and the fleet refuses every launch, take-over, revive and start on a conversation a live interactive window holds.
