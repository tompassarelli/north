- Proxy name follows a live window (north#636): no one runs `north fleet adopt` for the proxy. Every interactive window's SessionStart hook runs `north fleet adopt --name proxy --if-free`, which binds the name to that window only when no live session holds it (a parked or exited holder does not); fleet sessions, subagents and a start whose session id is not its own Claude process's conversation never run it. A message to `proxy` whose holder is dead, and a launch naming it as the parent, first bind the name to a live interactive window (`entrypoint` `cli` in `sessions/PID.json`) that no other session holds, the one on the holder's own conversation first and else the newest; the window takes the name over and the message is delivered to it, so a message never revives the dead holder. Adoption leaves a `host.sock` directory in the name's session directory that an older session host cannot bind, and the fleet refuses every launch, take-over, revive and start on a conversation a live interactive window holds.
