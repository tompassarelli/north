- Stand-in sessions (north#1632): `north fleet launch --provider standin --account local` starts a worker that calls no model. Its host, `north standin-host`, reads each turn's `Item:` and `Box:` lines, makes a lane in that repository writing one line to `lanes/standin/<lane>`, hands it in with those trailers and reports `Done:` with the ticket, so dispatch, the hand-in and the lander can be run at a set rate with no tokens spent.
