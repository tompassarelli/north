- Live claims: `threads claim`, `threads list` and `north fleet dispatch` share one claim rule in `crates/north-threads/src/threads/claims`. A claim is void when it predates its issue, its issue is closed or missing, or its owner is no live fleet session on any host (this host's registry, every other host's rows in the cached fleet table), and stale when its owner has been silent past its ETA (`overdue_ratio`); dispatch holds neither, and `claim` takes either over with an event naming why. Any other claim is live: `claim` refuses another owner and dispatch holds the issue, except that a box claim is admitted beside a live whole-issue claim when `--parent` names that claim's owner or a session above it, so a lead keeps an issue while the child it staffs holds the box it works. `threads ready`, `threads unowned` and `north work list` read the same list, and every mutating `north fleet` command has the claims of exited sessions released (Exited-claims sweep).
