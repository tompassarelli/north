- Credential broker: `north broker serve` is the one process that holds the GitHub App keys and the cloud API tokens, and every other process asks it over its Unix socket. `north broker github-token --app agent|lander [--repo NAME]... [--permission NAME:LEVEL]...` prints a one-hour installation token limited to those repositories and permissions plus metadata read, granted only within the ceiling its policy file gives the caller's uid (named by SO_PEERCRED), and a request above the ceiling is refused with the permission named; `north broker inspect --json` reads a token on stdin and prints what the broker granted it. A cloud call is plain HTTP on the same socket at `/PROVIDER/...` with a placeholder token: the broker forwards it with the real credential over TLS only when the caller's allowlist names its method and path, and never returns the credential. Clients find the socket at `NORTH_BROKER_SOCKET`, the system socket or their own `north broker serve --user`, which serves one user and exits after 30 idle minutes.
