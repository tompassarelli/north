- Stale-issue close: `north issue close-stale [--dry-run]` (hourly timer `north-stale-issues`) closes every open north and south issue created more than 24 hours ago, with a comment that names the 24-hour rule (2026-11-14) and copies nothing of the issue, and messages the issue's last owner session through `north fleet send` to rewrite the work as issues that can each be finished within a day. The owner is the session of the newest claim on the issue, whole or by box; an issue with none is closed with `no owner found`. The owner of an issue is messaged once: the message is sent and recorded in `~/.local/state/north/stale-issues.txt` before the close, so a run that fails at the close sends no second message. `--dry-run` prints each issue it would close and its owner and changes nothing. It exits 1 when any issue was not closed or a repository could not be read (north#1486).
