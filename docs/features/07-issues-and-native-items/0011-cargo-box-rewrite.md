- Cargo box rewrite: `north task rewrite-cargo [--dry-run] [--repo OWNER/REPO] [--tree DIR]` rewrites the Cargo commands (its build, test and nextest run verbs) in the code spans of every unticked box on the repo's open issues onto Buck2, by the rules posted on north#1115 for its cut-over: package patterns become `//crates/X/...`, name filters become `buck2 run` of each test target of the package whose sources mention the name, `--stress-count N` becomes a loop of N runs, and `--no-run` becomes `buck2 build`. It reads the workspace members and their test targets from the checkout at `--tree` (default `.`), prints each box before (`-`) and after (`+`), and refuses the whole run, editing nothing, when any box calls cargo in a shape no rule covers. Without `--dry-run` it re-reads each changed issue and edits its body.
