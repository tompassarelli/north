- Checkbox conversion, dry run: `north issue convert [OWNER/]REPO#N --dry-run [--manifest FILE]` writes a manifest with one row per unticked checkbox of the issue and creates nothing on GitHub. Each row carries a verdict (`leaf`, `third-level issue`, `prose`, `gate`, `held by a live claim`), the row it is indented under, a title, a type, labels, the checkbox line it stands for and the body its issue would get: the box word for word, its `Done when:` and `Needs:` lines on lines of their own, the lines of its own landing, and `Converted from OWNER/REPO#N, box SLUG.` so a later create run finds what it already made. A box a live claim holds stays a line of the body, a box that asks for the owner's decision is a gate, a nested box with no check of its own under a box that has a `Done when:` command is prose of that box, and a box with boxes of their own under it is a third-level issue. Leaves are Task and take the parent's `area:` label, the `category:` label of their own `Category:` line or else the parent's, and `waits:runtime` when their `Needs:` line names the live runtime, the lander or a native client, when they carry a date such as `not before DATE`, or when their `Verify:` line is farm, native or visual. The converter writes no title of its own: a title is the box's first clause when that is 15 to 80 characters, else it is left empty and the row is flagged for a person or a sorting worker. The command prints one count line, each refusal and the manifest's path and sha256, and exits 1 when the rows do not add up to the body's unticked checkboxes, the parent would pass GitHub's 100 children, or a row to be created has no title, a title over 80 characters, one that starts with a letter code or equals an open issue's or another row's, a leaf with no `Done when:` command in backticks and no `Verify:` or `Category:` line, a type or label the repository lacks, or, in a public repository, text the public deny-list matches. Edit the manifest and run again: each row's verdict, title, type and labels are kept for every box still in the body that no live claim holds, and the checks run on the edited rows. The manifest is `~/.local/state/north/convert/REPO-N.json` unless `--manifest` names it. `north issue convert [OWNER/]REPO --closed-boxes` lists every unticked checkbox on a closed issue of the repository with the open issue that holds the same text and whether it is ticked there, or `no copy`, and edits nothing. Either mode reads the repository from GitHub once per run, 100 issues a page.
