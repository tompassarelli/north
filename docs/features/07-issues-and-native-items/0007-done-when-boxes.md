- Done-when boxes: an open box whose Done when is a command writes it as ``Done when: `CMD` `` on its line. `north task check --done-when [--dry-run] [--main DIR] (--body-file FILE | REPO#N | --repo OWNER/REPO)` fetches origin main into a detached temporary worktree (or uses `--main DIR`), runs each such command there with a 10-minute limit, and prints one verdict line per box with its exit code. A box passes only when the expectation written after its command holds: `passes`, `succeeds` or `exits N` checks the exit code, `prints nothing` or `finds no match` needs empty stdout and an exit below 2, and `prints X` or `shows X` needs X in the output. A box with no stated expectation, or with a threshold or comparison such as `at most`, `under` or `<`, gets `judge`, which is never ticked. Without `--dry-run` it re-reads the issue body, ticks each passing box that is still open with `Evidence: ` naming the command, its exit code, the main sha and the date, attaches the last 20 lines of its output under the box, and edits the issue only when the body changed; failing boxes stay open. `--body-file` prints the ticked body instead.
