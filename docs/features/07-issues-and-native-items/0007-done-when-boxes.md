- Done-when boxes: an open box whose Done when is a command writes it as ``Done when: `CMD` `` on its line. `north task check --done-when [--dry-run] [--main DIR] (--body-file FILE | REPO#N | --repo OWNER/REPO)` fetches origin main into a detached temporary worktree (or uses `--main DIR`), runs each such command there with a 10-minute limit, and prints one `pass` or `fail` verdict line per box with its exit code. Without `--dry-run` it re-reads the issue body, ticks each passing box that is still open with `Evidence: ` naming the command, the main sha and the date, attaches the last 20 lines of its output under the box, and edits the issue only when the body changed; failing boxes stay open. `--body-file` prints the ticked body instead.
