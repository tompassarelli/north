- Native items: `threads new life|accounts|travel|ops TITLE [--due D] [--body -]` captures an item that lives only in threads.db (`life#1`), with `threads note`, `close` and `reopen`; `need`/`unneed` involving a native item are recorded locally, and `ready`, `show`, `list` and claims treat native items like GitHub issues without calling gh. Native items never reach GitHub: NorthThreads' gh calls, `safe-push` (commit messages, branch and tag names) and the `native-item-guard` hook (gh writes naming a native ref or quoting an item's title (20+ characters, 3+ words)) refuse them; `new` and `note` refuse text `gitleaks stdin` flags. Under `THREADS_NO_NATIVE` (exported by `agy`) or `CLAUDE_CODE_REMOTE` (cloud workers), NorthThreads hides native items and refuses to show them or the snapshot.
