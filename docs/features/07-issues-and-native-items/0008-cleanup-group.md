- Clean-up group: every feature, bug, tooling and performance issue in north, makgora and wisp carries three `Clean-up:` boxes (development tests turned down, scaffolding removed, nothing left for later). The `gh issue create` hook appends them to a new issue unless it is labelled documentation or research, `north cleanup-sweep [--dry-run] [north|makgora|wisp...]` appends them once to each open issue that lacks them and prints the count per repository, dispatch puts them in the brief of an issue's last unticked product box, and the `gh issue close` hook refuses an issue with an unticked Clean-up box. The "main is red" issue that north, makgora and wisp's Main is red workflow opens, rewrites and closes carries the `main-red` label, so it gets no Clean-up group and dispatch's notice of open issues with no Done-when box leaves it out.
