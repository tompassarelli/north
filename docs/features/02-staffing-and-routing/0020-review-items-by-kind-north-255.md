- Review items by kind (north#255): `north review-items PLAN [--author TIER]` splits a design review of PLAN into line items. Fact items, every path or `path:line` the plan cites, every north verb it names and every pair of its numbered boxes whose `Files:` overlap, run here through citation-check and the staffing-overlap file check and print `holds` or `FAILS`; a box pair holds only when `Needs:` orders it. Scenario items, one per `Enforced by` claim, go to the other model family than the author (`sonnet-high` for an Opus author, `opus-medium` for a Sonnet one); architecture items, one per design part that makes such a claim, go to Opus at a tier the author is not (`opus-high` for an `opus-medium` author), with the lens `simpler-alternative` where the part rejects alternatives and `decomposition` elsewhere. It launches nothing; the author defaults to `opus-medium`.
