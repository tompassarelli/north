- Usage resets: `north fleet usage` publishes fresh readouts through `threads ingest` to the authoritative ledger, with its existing offline spool. Remote clients read history from the mirrored snapshot and overlay fresh readouts in memory. A stale plan readout fails loudly. `north fleet usage` keeps each account's used percentages and reset times and appends reset availability and its source. `usage-web-read` reads the Claude usage page and account UUID inside automation Chrome, caches per-kind counts and expiry by hashed account in `~/.local/state/agents/usage/claude-web.json`, and preserves other accounts and the previous cache on failure. North never performs a reset: the grant is free, but Anthropic's Consumer Terms §3.7 forbid automated access to claude.ai and no provider command or API resets a plan window, so `north accounts` only shows the grants left and `north accounts reset [--dry-run]` logs the coordinator's account, time and Fable meter before and after, leaving the grant for Tom's own browser (`docs/rationale/usage-resets.md`).
