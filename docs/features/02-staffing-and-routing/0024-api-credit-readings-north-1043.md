- API credit readings (north#1043): `north fleet accounts --reading api:ORG USD` records the credit balance the operator reads in a provider console, and `north accounts`, `north fleet usage` and placement use it in place of the list-price estimate, naming the figure, its source and its time. `north fleet accounts --poll`, run by the fleet tick, reads each api organization's spend where the host holds its admin key and records what is left as a provider reading; `--probe` clears an exhausted mark once the provider answers again. A subscription account whose client refuses its first turn is marked unavailable with the refusal text, and `north accounts` lists it and placement skips it.
