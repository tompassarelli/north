- API credit readings (north#1043): `north fleet accounts --reading api:ORG USD` records the balance Tom reads in the provider console under `~/.local/state/north/api-readings/ORG`, and `north accounts`, `north fleet usage` and placement use it in place of north's list-price estimate, naming the figure, its console source and reading time with the estimate beside it; a provider reading from the provider's own spend reporting outranks a console one until the operator records a newer provider figure. `north fleet accounts --poll`, run by the fleet tick every ten minutes, reads each api organization whose Admin key this host holds, prices its hourly usage by model from the router's price table and checks the total against the provider's daily spend reporting, then records what is left of the credits recorded for that organization after the cost report's posted spend as its provider reading; the poller reads the key from its file and never prints it. An `api-exhausted/ORG` mark keeps the provider's refusal body verbatim and is written only for a refusal that names low credit; `north fleet accounts --probe` makes one one-token Messages request per held mark, clears the ones that pass, leaves a tombstone of the cleared text so a peer's host sync cannot restore that same mark, and rewrites the body of each mark it keeps from that probe's refusal, so a mark made before bodies were kept learns why the provider refuses. Every view reads one producer of an organization's credit (north#1063): the reading, else the list-price estimate of every unexpired grant charged with the spend of every pool name sharing the organization, closed only by a held exhausted mark; `north dash`'s billing section and the fleet screen's digest print each organization as `api:NAME $X left (SOURCE reading TIME, estimate $Y)`, and `north fleet usage` prints `exhausted` only for a held mark. A subscription account whose client refuses its first turn (subscription access disabled, signed out, a revoked login, or a weekly or five-hour limit) is marked under `~/.local/state/north/account-refused/LABEL` with the refusal text; `north accounts` lists it unavailable naming that text, placement and the contract probe skip it, a launch with `--account LABEL` is refused with it, and a 99% window reading counts as no headroom once the provider has refused. `north fleet accounts --probe` runs one one-turn Haiku prompt through that client and clears the mark only when it answers.
