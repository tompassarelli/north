- Context arms (north#636): `north dispatch` stamps a placed local Claude box that carries no tier or effort arm with `Arm: context-200k`, `context-300k`, `context-400k` or `context-500k`, drawn in equal shares by the seeded hash of its item and launch count, as the first `Arm:` line after `Tier:`. `north fleet launch` reads the stamp from the brief and starts the Claude session with `CLAUDE_CODE_AUTO_COMPACT_WINDOW` set to that window, so it compacts 33k below it (467k on the 500k arm, the settings default), and a relaunched or handed-over session keeps its window. `north dispatch --dry-run` prints each arm's boxes, closed boxes, kept boxes and cost per kept box across the fleet's ledgers over 30 days. The arms replace the handoff arms, which did not beat no-handoff on cost per kept box; [rationale/context-economics.md](../../rationale/context-economics.md) has the measurements.
