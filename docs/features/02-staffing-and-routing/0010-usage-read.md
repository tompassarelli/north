- Usage read: `north accounts --json` carries the latest reading of each account window from the threads ledger, with a `stale` flag. Each subscription account carries a Fable weekly meter beside its Opus and Sonnet meters, read from the same `weekly_scoped/Fable` provider row; until the provider reports that row, the meter reads the account's shared weekly window, so a Fable session's headroom is never unmetered. `--refresh` reads every usage and billing adapter here and, unless `--local`, on each other machine holding a labelled account, records the readings and rewrites the pace gate; `--write-pace-gate` rewrites only the gate, `--fast PROVIDER` answers through its exit code whether fast mode is on, and `--gate PROVIDER` is `north fleet pace gate PROVIDER`. The flags are in `north fleet usage --help`. Publishing: `north fleet usage` publishes fresh readouts through `north threads ingest` to the authoritative ledger, with its existing offline spool. Remote clients read history from the mirrored snapshot and overlay fresh readouts in memory. A stale plan readout fails loudly. `north fleet usage` keeps each account's used percentages and reset times and appends reset availability and its source. `usage-web-read` reads the Claude usage page and account UUID inside automation Chrome, caches per-kind counts and expiry by hashed account in `~/.local/state/agents/usage/claude-web.json`, and preserves other accounts and the previous cache on failure. Resets: north never performs a reset. The grant is free, but Anthropic's Consumer Terms §3.7 forbid automated access to claude.ai and no provider command or API resets a plan window, so `north accounts` only shows the grants left and `north accounts reset [--dry-run]` logs the coordinator's account, time and Fable meter before and after, leaving the grant for the operator's own browser (`docs/rationale/usage-resets.md`).
