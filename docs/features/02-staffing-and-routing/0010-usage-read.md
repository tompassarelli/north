- Usage read: `north accounts --json` carries the latest reading of each account window from the threads ledger, with a `stale` flag. Each subscription account carries a Fable weekly meter beside its Opus and Sonnet meters, read from the same `weekly_scoped/Fable` provider row; until the provider reports that row, the meter reads the account's shared weekly window, so a Fable session's headroom is never unmetered. `--refresh` reads every usage and billing adapter here and, unless `--local`, on each other machine holding a labelled account, records the readings and rewrites the pace gate; `--write-pace-gate` rewrites only the gate, `--fast PROVIDER` answers through its exit code whether fast mode is on, and `--gate PROVIDER` is `north fleet pace gate PROVIDER`. The flags are in `north fleet usage --help`.
