- Usage read: `agents usage` is served by `north usage`: the latest reading of each account window from the threads ledger, as a per-account table of windows, billing, resets, burn, plan and cost, or with `--json` as JSON carrying a `stale` flag. `--refresh` reads every usage and billing adapter here and, unless `--local`, on each other machine holding a labelled account, records the readings and rewrites the pace gate; `--write-pace-gate` rewrites only the gate, `--fast PROVIDER` answers through its exit code whether fast mode is on, and `--gate PROVIDER` is `north pace gate PROVIDER`. The flags are in `agents --help`.
