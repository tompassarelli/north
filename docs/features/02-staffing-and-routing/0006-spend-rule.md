- Spend rule (north#702, north#1076, docs/rationale/spend-rule.md): north holds back no launch on usage grounds; only the owner's API hold (`[accounts.claude] api_hold`, which refuses every API organization to every caller of every role, operational ones included, and which only an edit of that record lifts), the provider's own limit and the declared operational reserve stop a new start, and each refusal names which. A worker launch registers its name on the ledger host in the transaction that claims it. `north spend [--json]` prints the week points left across accounts and the worker sessions working, then the waste of the last 24 h: needs workers recorded with `north fleet need`, launches placed beside a holder (the `dup:` note earlier sessions recorded), and revert tickets withdrawn as false, each unmeasured with its reason when its record is unread. `north config agents plan` orders candidates by weekly room per hour to the reset and skips any at a provider limit.
