 - Claude account profiles: `north fleet launch --provider claude --account LABEL --name NAME PROMPT` uses the account's local profile and records its label for restarts. Omitting `--account` on a Claude launch (not `--test`) runs it on the account placement picks, the target `agents plan --place` prints, and a held placement refuses with `held: REASON` and exit 1 like every launch refusal; a named account that placement refuses stays refused, and a Codex launch still needs `--account`. South owns account IDs, host profiles, plan selections and required plans for automatic routing. `agents sync` projects the default Claude harness files into those profiles while credentials and session history stay separate. A profile awaiting its required plan is available explicitly but is excluded from automatic routing until its OAuth tier confirms that plan.
