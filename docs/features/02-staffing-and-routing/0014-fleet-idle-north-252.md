- Fleet idle (north#252): a session host parks an idle session after its idle limit (`north fleet launch --idle-exit`), and a wake while the prompt cache is warm resumes on it. A large unfinished session is sent a bare `/compact` frame shortly before its cache expires and is parked after it. A session whose last report opens Done, Not done, Split, Stop or Blocked, that has a parent or task and parents no live session, exits instead of parking; its transcript and worktree stay, and `north fleet send` or `north fleet revive` brings it back. A host journals each prompt until Claude echoes it into a turn, so a prompt queued just before a host restart is written again by the next host instead of lost, and `north fleet list` calls a session working while its journal holds a prompt (north#245).
