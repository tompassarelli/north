- Buck2 targets from the Cargo manifests (north#1115): `north buck targets` writes `BUCK` at the repository root and in each `crates/<dir>` from `cargo metadata` and the manifests' `[lints]`, so the Buck2 graph cannot drift from Cargo's while both exist; `--check` writes nothing and exits 1 naming each `BUCK` that differs. Each library is `//crates/<dir>:<crate>`, each binary `:<bin>` (`:<bin>-bin` when it shares the library's name), each unit-test harness `:<target>-unittest`, each integration test `:<crate>-test-<name>` and each example `:<crate>-example-<name>`; third-party crates are `//third-party:<crate>`. Every test is a `north_rust_test` carrying its nextest binary id, every package has the `:files` its tests read at run time, and `CARGO_MANIFEST_DIR` is the package path from the repository root. Every target of a crate carries its workspace-unified features, Cargo's lint and `--check-cfg` flags, and the `CARGO_*` variables its sources read. A file a crate reads through `include_str!`, `include_bytes!`, `include!` or a `#[path]` module outside its own source directory is exported by the package that owns it and mapped into the crate's source tree at its repository path. Design and the feature decision in `docs/rationale/compile-reuse.md`.
