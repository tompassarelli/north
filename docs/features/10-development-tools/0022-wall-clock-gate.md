- Wall-clock gate: `north land scan test-integrity BASE..HEAD` also refuses a changed Rust test file that sleeps (`thread::sleep`, `tokio::time::sleep`) or asserts on `.elapsed()` or `Instant::now()` against a bound outside a `loop`, `while` or `for` that polls a condition, because a fixed sleep or a wall-clock bound decides a verdict on how fast the host runs: on 2026-11-07 the frozen land check test failed on loaded hosts and the lander paused every landing (north#783). Code under test takes its time from an injected clock, such as the deadline's `NORTH_CAPACITY_DEADLINE_CLOCK` directory a test writes to, or from a release file the test creates, and the test waits on the state it needs. The whole file of each changed test file is judged, there is no allowlist, and `north_diff_gates::wall_clock_gate` holds the rule.
