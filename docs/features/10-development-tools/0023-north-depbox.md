- North depbox: `north depbox fetch|run -- COMMAND...` runs a command in the dependency sandbox, `run` with no network for builds and tests and `fetch` with the network for installs and fetches (`crates/north-capacity-host/src/capacity/depbox.rs`). A build host runs each offloaded command through it, a landing fetches its dependencies through `fetch`, and the toolchain shims in `bin/` (`cargo`, `rustc`, `bun`, `node`, `npm` and the rest) send every call into it, so a lane's build and package scripts never run outside it (south#93). A land check that reads a host input sees, read-only, only the store entries its committed pins name (north#1148). Why: docs/rationale/worker-sandbox.md.
