- Task split (north#1236): `north graph split --base SHA --task FILE` reads only the task text and the base commit's tree (crate edges from its manifests and Cargo.lock, module parents, and the defining and referring files of each symbol a plan names, by `git grep` at the base) and makes one tool-less planning call on a public repository, then writes boxes: a first box holding the skeleton (new files as declared empty modules, every manifest and Cargo.lock edit, and shared signatures with `todo!("split-ID")` bodies) that lands alone, one box per part with its write set and check, where no two parts name one file (parts that would share a file, or where one adds a symbol the other uses, become one part), and a last box whose check, `north graph split --check ID --parts N`, passes once every part carrying `Split-box: ID part K` is on origin/main and no stub remains, recording the first box's commit so an abandoned task is undone by reverting it. A plan that contradicts the base is refused with one line that goes back to the planning call once; the record keeps the split's wall time and each call's tokens. `--plan FILE` splits a stored answer and `--prompt FILE` writes the planning input instead of asking.
