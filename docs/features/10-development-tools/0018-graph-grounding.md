- Graph grounding (north#669): the UserPromptSubmit grounding hook and `north brief new --category C --item REPO#N` read the fact graph for each issue (`north#634`) and file path a message names and add its neighborhood to the grounding context: for an issue, its open boxes, each ticked box's Done claim marked as the worker's claim or as observed when the checker passed the commit it names, recent landings and corrections made in the sessions that worked on it; for a file, the functions the coverage map holds, the tests that reach them, recent landings that touched it with the issue each served, and corrections in those sessions. The hook only reads the graph that `north graph ingest` built (read-only open, never an ingest) inside the hook's existing 600 ms retrieval bound, and says nothing when the graph is absent or the name unknown. `north land follow` runs `north graph ingest` after each landing, under a lock so concurrent follows ingest one at a time.
