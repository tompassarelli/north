- Product verification: `verify-north` builds north from the checkout around the current directory (or takes `--north PATH`); with `--claude-account A --from-claude-login` it first makes account A's profile under `~/.local/state/north/profiles/claude-A` from Claude Code's login when A has none, which is the account step of `nix run github:tompassarelli/north#setup`; then walks the spine end to end on a scratch repository with a bare origin and a scratch state root (`XDG_STATE_HOME` and `NORTH_TEST_ROOT`): `north land serve` serves the scratch queue, the judged north's outside broker answers on its socket, a confined worker command commits a change, passes `safe-push --check-only` and queues the lane with `north hand-in`, and the lander lands the commit on `origin/main` (north#1650). A separate cleanup process terminates the child processes, removes the scratch repository, its landing queue and the state root, and asserts none of its processes survive.
- A failed verify-north step keeps its evidence (`pushes.tsv`, `lander.log`, `broker.log`, `processes`, `land-queue`) under `${XDG_STATE_HOME:-$HOME/.local/state}/north/verify-north/failed/STAMP` before cleanup removes the scratch root (north#1103).
