- Graph ingest (north#669): `north graph ingest [--db PATH] [mirror|ranking|ledger|pushes|touches|decisions|corrections|coverage]` loads what north already records into the fact graph from the local copies, never the GitHub API: issues and task-list boxes from the mirror, checks and tasks from the ledger, the push log, the files each landed commit changed (from the git log of its checkout, last 30 days), the decision log, the corrections ledger and harness/corrections.toml, and the coverage map. Each source is told as a set, so a rerun over unchanged sources asserts and retracts nothing, and a box unticked or an issue closed retracts what no longer holds. Writers stay apart: a ticked box naming `owner: SESSION` is that session's quoted claim `(SESSION :claims (box :done-at SHA))`, never a bare fact, and a check is an assertion by `checker`, so "which Done claims on north#634 have no checker observation" is one `ask` over `assertion` and `quoted` (query in `docs/graph.md`). A source that cannot be read is skipped with its reason and exit 1; the others still load.
