- Stub-exec gate: `north land enqueue` refuses a landing whose changed Rust files under `crates/`, `src/` or `tests/` make a file executable outside `north_base::foundation::shim` (a `from_mode(0o7..)`, a local `fn executable(path: &Path, ..)` or an `fs::copy` of a built or `bin/` binary) and are not in the `.stub-exec-allowlist.json` the landing carries, or that leave an entry whose file no longer needs it; a repository without the allowlist is not judged. The `stub_exec_policy` test checks the whole tree against the same list in the lander. A stub written in the test process can be inherited writable by a concurrent fork and fail to exec with `Text file busy`; from 2026-11-04 to 2026-11-05 lanes that missed the policy were refused 6 times after a full lander precheck, 2 of them candidates stacked on another lane's stub (north#360).
