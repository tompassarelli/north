- Disk budget: a host's `[hosts.NAME.disk_budget_gib]` in orchestration.toml gives each store on its shared root disk a GiB share, and every sweep reads its cap from it. The stores are `cargo_target` for each shared cargo target `north lane reclaim` and `north land clean --sweep` trim, `map_store` for wisp's per-host map-build store, `makgora_evidence` for retained Mak'gora evidence, `mutant_cargo` for the mutant step's cargo target `north lane reclaim` trims, and `capture_batches` for the capture queue's batch folders `north lane reclaim` deletes oldest first once a day idle with their results kept, never one with a queued or running job, a `PINNED` file or a holder. A store whose share is unset keeps its built-in cap (10 GiB per cargo target and mutant target, 8 GiB map store, 15 GiB capture batches; the evidence store has none and is never deleted on a host that names no share). `north capacity disk-share SHARE` prints this host's share in GiB (nothing when unset), which wisp's map store reads.
