- Disk budget: a host's `[hosts.NAME.disk_budget_gib]` in orchestration.toml gives each store on its shared root disk a GiB share (`cargo_target` for each shared cargo target `north reclaim` and `north land-clean --sweep` trim, `map_store` for wisp's per-host map-build store, `makgora_evidence` for retained Mak'gora evidence, `mutant_cargo` for the mutant step's cargo target `north reclaim` trims, `capture_batches` for the capture queue's batch folders `north reclaim` deletes oldest first once a day idle with their results kept, never one with a queued or running job, a `PINNED` file or a holder); every sweep reads its cap from it, and a store whose share is unset keeps its built-in cap (10 GiB per cargo target and mutant target, 8 GiB map store, `evidence_budget_gib`, 15 GiB capture batches). `north capacity disk-share SHARE` prints this host's share in GiB (nothing when unset), which wisp's map store reads.
