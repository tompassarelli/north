- Compiler cache: every user session on the laptop and gex45 exports `RUSTC_WRAPPER` as sccache (firn module `sccache`) with its local disk cache in `~/.cache/sccache` capped at 30 GB (`SCCACHE_CACHE_SIZE`), so a lane whose `Cargo.lock` has no seed sibling still reuses compiled registry crates; `SCCACHE_BASEDIRS=~/code` lets worktrees share Rust entries and the CMake launcher (a per-lane server rooted at the lane) lets them share C and C++ entries, `depbox run` passes the variables and binds the cache directory while `depbox fetch` does neither, and sccache skips incremental crates, so each project keeps its `CARGO_INCREMENTAL`.
