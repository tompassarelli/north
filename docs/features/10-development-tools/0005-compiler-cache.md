- Compiler cache: every user session on the laptop, gex45 and ccx33 exports `RUSTC_WRAPPER` as the firn module `sccache`'s wrapper. Its local disk cache lives in `~/.cache/sccache`, capped at 30 GB (`SCCACHE_CACHE_SIZE`), and a shared level sits behind it: an rclone WebDAV store on nexus, capped at 20 GiB, open only to the wg-nexus peers. A crate compiled on one host is therefore a hit on the others. The wrapper roots `SCCACHE_BASEDIRS` at the checkout that rustc writes into, with one sccache server per checkout, so worktrees share Rust entries too; CMake uses the same wrapper as its compiler launcher. A local nginx relay answers every failure of the store as a miss within 3 s, so a nexus or network outage leaves builds on the local disk. `depbox run` passes the variables and binds the cache directory, and its network-less sandbox reaches the relay through `/run/sccache-remote/http.sock`; `depbox fetch` does neither. sccache skips incremental crates, so each project keeps its `CARGO_INCREMENTAL`.
