- Code health: `code-health` (in `harness/code-health/`) measures hand-written TypeScript, JavaScript, Rust and C against the repo's committed `structure.toml` through `ast-grep`: file and function size, complexity, import cycles, layer violations, fan-in and fan-out, co-change and churn hotspots. `gate BASE HEAD` refuses new debt and lets existing debt stay put, `check FILE` applies the same rules to one dirty file, and `signal` says when a recurring review is due; the `code-health-tick` timer then starts a uniquely named review session per repository. `north health` reports a `capacity-watchdog` timer whose service keeps failing and opens a north issue for it. Subcommands and flags are in `code-health --help`.
