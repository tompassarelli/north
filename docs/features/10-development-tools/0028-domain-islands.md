- Domain islands: `north code-health domains [--repo DIR] [--rev REV]` reads the `[domains]` table of structure.toml and exits 1 for each crate whose modules form more islands than `max_islands` allows (`✗ domains`). The modules are the top-level modules of the crate, or, when its only top-level module is a directory such as `src/ops/`, the families inside that directory. Two modules share an island when one names the other through `crate::` (or `super::` from a file that is itself a top-level module), or both name the same workspace crate other than north-base. A crate with a `[[domains.allow]]` entry (a `crate` name and a `reason`) is reported and not refused. The landing's code-health gate refuses a change that touches the source of a refused crate, so a grab-bag crate such as the old `north-ops` cannot grow back once it is over its bound (north#1435, docs/rationale/north-ops-split.md).
