- Retention: `north retain [--dry-run] [--host H] [--archive DIR]` (run on the laptop) reads the GPU host's `~/.local/state/makgora/evidence` and `capture-queue/batches` over ssh and, for each folder whose newest file is older than `evidence_retention_hours` or `capture_batch_retention_hours` (harness/defaults.toml), copies it into `~/archive/makgora-gex45/FAMILY/`, compares the sha256 of every file and the target of every symlink against the source, re-reads the source manifest, and only then deletes the source folder. Expired folders go oldest first in batches of up to 200 entries or 256 MiB, each batch taking one manifest read, one tar stream, one re-read and one delete over ssh; once `retention_budget_minutes` have passed it starts no new batch, prints what each family left for the next run and exits 0, and every run ends on a line giving the entries, MiB and MB/s it archived. It also archives each `~/.local/share/makgora-build-inputs/store/FAMILY/HASH` version (not `views` or `locks`) that no 64-hex pin names in `build-inputs/`, `ts/stage-thumbnails.json` or `tools/animations/mdl-exporter4.pin` on makgora `origin/main` (fetched first), on any other `origin` branch or in the working tree of any `~/code/makgora/*` or `worktrees/*` checkout, and each `store/derived/STEP/KEY` cache entry (folder or file; derive rebuilds a missing key), once older than `build_input_retention_hours`, into `build-inputs/FAMILY/`, making the sealed read-only copy writable before it is moved or deleted; when origin/main names no pin or the read fails, no store version is archived. A folder holding a `PINNED` file, held open by a process (cwd or open file), holding a socket, fifo or device, or whose archive copy differs is kept.
