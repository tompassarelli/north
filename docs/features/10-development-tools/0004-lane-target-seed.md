- Lane target seed: `north lane seed [DIR]` gives a checkout with no `target/` a reflink copy of the newest idle sibling `target/` built from the same `Cargo.lock`, and deletes the fingerprints of the workspace's own packages, so a new lane's first build starts warm. The devShell hook, `north depbox` and the canary run it. On btrfs the copy is a subvolume of its own, so home snapshots never keep a lane's build output; on a filesystem that cannot share extents it seeds nothing and the lane builds cold, since a full copy there filled a build host's disk (north#1036). A host whose `build_system` is `buck2` gets only an empty `buck-out/`, because the shared Buck2 action cache replaces the seed. What a seed saves and what replaces it: docs/rationale/compile-reuse.md, "Lanes".
