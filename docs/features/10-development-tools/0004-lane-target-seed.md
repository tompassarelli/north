- Lane target seed: `north lane seed [DIR]` gives a checkout with no `target/` a `cp -a --reflink=auto` copy of the newest idle sibling `target/` and deletes the fingerprints of packages that must rebuild, so a new lane's first build starts warm. It is run by the devShell hook, by `depbox` before its sandbox (which hides `north` and the sibling checkouts) and by `harness/scripts/canary.sh` for the scratch lane it makes in `worktrees/`, and acts only on a checkout with no `CARGO_TARGET_DIR` other than its own `target`, as the land checks set it. The source is the newest idle `target/` of the same container's `main` or `worktrees/*` that holds a `CACHEDIR.TAG` and a byte-identical `Cargo.lock`, copied with `incremental/` included; the deleted fingerprints are those of every `Cargo.lock` package without a registry or git source. A sibling whose `.cargo-lock` is held mid-build is skipped (compile-times.md, "Measured: a new lane's first build").
