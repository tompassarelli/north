- Lane target seed: `north target-seed [DIR]`, run by the devShell hook, gives a checkout with no `target/` (and no `CARGO_TARGET_DIR` other than its own `target`, as the land checks set it) a `cp -a --reflink=auto` copy of the newest idle `target/` of the same container's `main` or `worktrees/*` that holds a `CACHEDIR.TAG` and a byte-identical `Cargo.lock`, then deletes the fingerprints of every `Cargo.lock` package without a registry or git source so those rebuild; a sibling whose `.cargo-lock` is held mid-build is skipped (compile-times.md, "Measured: a new lane's first build").
