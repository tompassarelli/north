- Crate split: `north split move-module [--dry-run] [--from FROM] --crate CRATE [--allow-test-item NAME]... [--target-dir DIR] MODULE...` moves one or more modules (`tui`, `ops/tempo`) out of `crates/FROM` (default `north-core`) into the sibling crate `crates/CRATE` as byte-identical `git mv` renames, writes that crate's `Cargo.toml` with exactly the in-repo and workspace crates the moved files name and its `lib.rs` as re-exports plus a `mod` list, wires the workspace and the root callers, rewrites path mentions except in `*_tests.rs` and `fixtures/`, adds the paths to the moved module's `structure.toml` entry without widening any `may_use`, widens only what `cargo check` names as private, refuses a `#[cfg(test)]` item unless `--allow-test-item` names it, ends with `cargo test --workspace --no-run` and the new crate's tests, and prints one `Dependency:` trailer per added dependency; a second run is a no-op. Method in `docs/rationale/crate-split.md`.
