- Dependency sandbox: `depbox fetch|run -- CMD...` runs installs, builds and tests in bwrap with the home directory masked except the git toplevel (rw), its common dir and ~/.gitconfig (ro), the bun, cargo and nix caches (rw), each checkout's own target/ as its cargo target, because cargo hashes a path package by its workspace-relative path, so worktrees sharing a target or build directory receive and run one another's outputs (a CARGO_TARGET_DIR other than the checkout's target/ is ignored with a warning; north land-clean and north reclaim remove the target/), ~/.rustup, the firn CLI runtime and the immutable firn and north pins (ro); /run/user, /run/secrets.d and /tmp are empty, the environment keeps only PATH, HOME, USER, LANG, TERM, NIX_PATH and the SSL cert variables, no_new_privs blocks sudo, and `run` has no network. Before the sandbox starts, depbox roots the checkout's `nix develop` shell (`nix print-dev-env --profile`, keyed by the hash of the tracked .nix files, flake.lock and rust-toolchain files, under `~/.local/state/depbox/shell-roots`, built on the host with its network the first time a key is seen even under `run`, with a link to /dev/null for a day where the build fails) so `nix-collect-garbage` cannot delete it and break offline runs, and drops roots unused for 7 days.
