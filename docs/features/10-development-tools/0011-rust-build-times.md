- Rust build times: `north code-health build-time --repo DIR [--workspace REL [--leaf REL --hub REL]] [--samples N] [--ledger FILE] [--rev REF] [--file]` times a cold `cargo build --timings` (critical path from its report) and the median of N one-line edits in a leaf and in the most-depended-on module for `cargo build` and `cargo test --no-run`, in a scratch target without sccache, appends a row to `~/.local/state/north/build-times.tsv`, and exits 1 when the leaf-edit `cargo test --no-run` exceeds the workspace's `[[build_time]] test_no_run_seconds` in `structure.toml`. `--rev REF` fetches origin and measures a detached checkout of REF that it removes afterwards; `--file` keeps one rolling issue per repo with a split box for each workspace near (75%) or over its threshold, edits it after each run and closes it when all are within. gex45 runs it daily for north (`build-time.timer`); method and the measured table in `docs/rationale/rust-build-times.md`.
