- Rust build times: `north code-health build-time --repo DIR [--workspace REL [--leaf REL --hub REL]] [--samples N] [--ledger FILE] [--rev REF] [--file]` times a cold `cargo build --timings` (critical path from its report) and the median of N one-line edits in a leaf and in the most-depended-on module for `cargo build` and `cargo test --no-run`, in a scratch target without sccache, appends a row to `~/.local/state/north/build-times.tsv`, and records the host load per thread beside it (a run above the workspace's `contention_ceiling` is `contended`: exit 0, nothing ticked), and exits 1 when the leaf-edit `cargo test --no-run` exceeds 10 s, a cap in code that a `[[build_time]] test_no_run_seconds` in `structure.toml` may only lower (a larger value is ignored with a warning); the verdict is `over`, `near` (from 75%) or `within`. `--rev REF` fetches origin and measures a detached checkout of REF that it removes afterwards; `--file` keeps one box per workspace near or over the cap in the "Split north-core" section of north#259, edits its numbers after each run and ticks it once the workspace is within. gex45 runs it daily for north (`build-time.timer`); method and the measured table in `docs/rationale/rust-build-times.md`.
