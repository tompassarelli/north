- Effect kit: `effect-kit init|check|sync|upgrade|scan [ROOT]` (in `agent-machinery/scripts/effect-kit.mjs`) keeps one setup in every TypeScript project that depends on `effect`, configured by its `effect-kit.json`. `check` fails on drift between the vendored `repos/effect.json` version and the lockfile's `effect`, any Effect language-service diagnostic (all count at error severity), a plugin that ignores them in the exit code, or a raw spawn, timer, promise or fetch outside Effect in host tools, and prints the counts. `init` vendors upstream at the installed version and sets the plugin, `sync` moves the vendored copy, `upgrade` bumps Effect packages to the newest stable release at least 7 days old, and `scan` lists `ROOT/*/main` projects (default `~/code`) that depend on `effect` without `effect-kit.json`.
