- Features index: `north docs features-index` writes the features index from `docs/features/`, the `_header.md` file, then one `NN-name` directory per section holding its `_title.md` and one `NNNN-name.md` file per record, each shown by its first sentence with a link when it says more. To add a feature, add a file under its section; the index itself is not tracked, and the lander writes it. The other generated registries work the same way, one file per unit and a generator each: `north docs rationale-index` writes `docs/rationale/README.md`, `north docs help-index` `src/cli/help.txt`, `north docs reference-index` `src/cli/reference.txt`, `north docs verbs-index` `src/cli/verbs.rs` and `north docs structure-index` `structure.toml`. Each has `--check`, which is also a land check; `build.rs` writes the last three before the crate compiles, the lander regenerates an index after each lane that changes its sources, `north merge-driver continue` regenerates one a rebase stopped on, and a lane that commits a generated file is refused (north#729). Why: docs/rationale/docs-architecture.md.
