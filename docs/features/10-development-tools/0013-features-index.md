- Features index: `north docs features-index` regenerates `docs/features.md` from the one-file-per-feature tree under `docs/features/` (`_header.md` for the text above the first section, one `NN-name` directory per section holding `_title.md` and one `NNNN-name.md` file per entry, all joined in name order with a blank line between entries unless both are list items); to add a feature, add a file under the section's directory, never edit `docs/features.md` by hand. `--check` fails when `docs/features.md` is stale, which is also a land check, and `--root DIR` names the checkout.
