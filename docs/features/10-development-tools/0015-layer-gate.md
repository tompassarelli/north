- Layer gate: `north code-health layers [--repo DIR] BASE HEAD` reads HEAD's `structure.toml` and exits 1 for each reference a changed Rust file adds, as a `use` item or an inline `crate::`, `self::`, `super::` or crate-name path, that breaks a `[[module]]` `may_use` rule (`✗ layer`) or the planned crate DAG in `[[crate_dag.crate]]` (`✗ crate-dag`, the twelve-crate plan of `docs/rationale/crate-split.md#next-cuts`, transitive, crate roots exempt). A reference the file already made on BASE, even after a rename, stays put. It runs as a land check over the whole diff, so a breach is refused before landing, not only at edit time.
