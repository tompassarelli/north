- Loop report: `north report` prints the latest `calibration` batch per kind, the latest `prior` batch, the 7-day stall recovery line, spawn-gate denials and each project's latest goal score. Each calibration cell shows its age, n and `(uncalibrated: <reason>)` when under n=5 or older than 7 days. Each prior batch prints as `WAIT <default> n=<n>/<need>` below its need, `MEASURABLE-NOT-MEASURED` at its need while no sweep result is recorded for it, and `SETTLED` only when its `settles_when.measured` records one. The stall line is the one `north ledger worker --summary` prints, the denials are counted over 7 days by gate (capacity, flow, pace), and each goal score shows on-date, in-budget with spent against budget, and spec.
