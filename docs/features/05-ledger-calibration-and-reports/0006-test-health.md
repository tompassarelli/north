- Test health: `test-health [--now ISO] [--out FILE] [--html FILE] [--no-fetch]` writes one JSON row per active repo (latest main CI wall per landing gate against its budget, five-kind census share from the T5 TSVs and wisp#120, unique-kill share, a 30-day test-file and CI-wall trend, and spot-check verdicts from `handoffs/test-health-spotcheck/<repo>.json`) and renders it as a self-contained HTML page; every number links to its run, commit or file, and a fixed `--now` gives identical output. Completed run jobs are cached in `~/.cache/test-health`.
