- Worker delivery costs: `north worker-ledger` records each finished worker as a run in the threads ledger and `--summary` reports brief-to-landed minutes, dollars per done box and completed-worker concurrency per model, effort and project; dollars come from weekly usage readouts allocated to the token samples of active runs, and a missing interval prints an unknown cost. A fleet session is reread while its transcript changes, so its latest decided report wins, and a session safe-push recorded landing counts as landed. Senders reach the ledger host through `north threads ingest`, which holds an exclusive lock beside the ledger with no network call inside it, exits 75 for the sender to spool when the lock is busy, and logs each ingest's wait and hold to `ingest.log`. Flags are in `north worker-ledger --help`.
