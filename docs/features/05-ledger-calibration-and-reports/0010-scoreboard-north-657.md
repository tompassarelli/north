- Scoreboard: `north scoreboard` prints, for the last 7 days and the 7 days before, Tom's corrections per active hour, ask to first landed commit, landing queue to main and verification after the push (median and p90), rework within 48 h per landing, worker first-try success by category, and proxy recommendations filed as an issue the same turn, each with its record; [rationale/scoreboard.md](../../rationale/scoreboard.md) sets them against published figures. The fleet tick records it weekly (`north scoreboard --record`, the `scoreboard` loop in `harness/loops.toml`) and tells the proxy which numbers got worse, comparing weeks of at least five observations moving past 10%. `north scoreboard --rework --since 7d` counts reworked landings by judge rule (revert, named commit, named issue, Fix subject with file overlap, red-main culprit) and by class of change (control-plane code, gates, tests, tables, docs), each with its triggering commit, read from the verdict cache `north-rework-detail.json`; a verdict stored without them is judged again once (north#657).
