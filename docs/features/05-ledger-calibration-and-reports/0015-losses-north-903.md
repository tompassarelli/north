- Harness losses list (north#903): `north dash losses [--since 24h] [--until DATE] [--repo north]` prints the bar "first tries lost to the harness" count and every first try it charged in the window, each with its end, session, item, class and the boundary row that decided the class, the classes ranked by count. `--until` sets the window's end, so `north dash losses --since 24h --until 2026-11-08T03:15Z` reproduces [the 2026-11-08 list](../../rationale/harness-losses-2026-11-08.md); with no boundary row the row says whether the class came from the run's final report, and the command quotes no report text itself.
