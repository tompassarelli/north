north — coordinate work, agents, and time — the complete reference
(`north help <topic>` is one section; bare `north` is the daily card)

WORK — threads: thought → fact → outcome
  north capture "<title>" [owner]               mint a committed thread from one thought (zero ceremony)
  north show <id|slug|substring>                one thread's facts + body; resolves id, slug, substring
  north tell <id> <pred> <value>                assert a fact through the fact server (serialized, rule-checked)
  north retract <id> <pred> <value>             retract a fact through the fact server
  north threads [--all]                         thread-kind overview: active drivers, top ready, counts
  north ready [--all]                           committed + unblocked work; manual queue order, leverage fallback
  north queue move <thread> <before|after|first|last> [anchor]
                                                durably reorder the derived ready lane without mutating status
  north next                                    the recommended next pull
  north report                                  recent shipped outcomes
  north blocked                                 threads waiting on a depends_on target
  north leverage                                what unblocks the most downstream work
  north agenda                                  calendar projection over do_on: overdue / today / upcoming
  north needs-review                            judgments whose inputs moved; unevidenced bars; promotable drafts
  north resolve <ref>                           canonical thread id for a ref (id, slug, or substring)
  north evidence record "<bar>" "<result>"      bind done-bar evidence to this exact managed run
                                                --thread <id> — no reservation in env: record unreserved thread evidence
  north recover <@attempt:sha256> [--json]      show one attempt's Store-authoritative safe next action (read-only)
  north bars list|prune <thread>                groom a thread's done_when set; prune retires evidenced bars
  north worktrees [repo] [--json]               every repo's worktrees/ lanes: drift, dirt, age, owning lane/concern
  north worktree lander [repo]                  landing reconciliation: harvest lane refs already merged to main
  north linear get|import|plan|sync             mechanical Linear bridge (sync is plan-only unless --apply)
  north merge <from> <to>                       fold one node into another; refs follow

AGENTS — delegate work, drive and observe agents
  north delegate "<task>"        hand work to a new lane; intake classifies atomic vs composite
                                 --role <worker> — atomic: exactly one selected worker
                                 --composite — 2+ independent pieces: hydrates an orchestrator
                                 --thread <id> — bind an existing thread
                                 --handoff <artifact> — adopt one validated session-hard-cap artifact
                                 in chat, /delegate does this with session context riding along
  north agents [--json]          live agents now + the stable machine roster
  north lanes                    last 24h lane receipts: done, failed, working, killed, or never acknowledged
  north spawn <role> "<prompt>"  compose a worker from Orchestration's staffing catalog
                                 --provider auto|anthropic|openai — select or auto-route the provider
                                 --taskGrade/--domain — independently override stock staffing axes
                                 --topology — bespoke compositions only; stock topology is fixed
                                 --tier/--reasoning/--posture — capability, deliberation, posture
                                 --assessment JSON|@file — selection sidecar (required for max)
                                 --pin-evidence JSON|@file — typed reason + <=24h expiry for exact pins
                                 --rationale "why" — required for a bespoke role
                                 --doctor [--deep|--canary|--json] — test every dispatch invariant at once
                                 in-harness agents dispatch via MCP: mcp__north__dispatch / spawn
  north templates                Orchestration's reusable stock templates and routing defaults
  north watch <id>               tail an agent's transcript
  north msg <id> "<msg>"         inject a message into a running agent
  north goal <id> "<goal>"       redirect a running agent's goal
  north trace <id>               diagnose one agent's lifecycle; flags the first failing stage
  north wip [--check]            live managed lanes vs floor (--check: exit 3 on shortfall)
  north escalate needs-replan …  checkpoint scope overrun; route it up the live parent chain
                                 --summary/--checkpoint/--seam/--propose — the structured payload
  north listen <agent-id>        arm the real-time interrupt listener (background task; dormant)

COMMS — attention between people and agents
  north inbox [--as <recipient>]        durable messages waiting on you
                                        --as <recipient> — inspect another recipient's inbox
  north mention <recipient> "<body>"    durable sender-driven request; offline recipient allowed
                                        --about <thread> — attach the request to a thread
  north interrupt <recipient> "<body>"  urgent sender-driven request; live recipient required

ROUTING — providers, accounts, dispatch posture
  north config                                  every posture setting + routing policy, one report
                                                north config dispatch <mode> — native · managed · auto
                                                north config guards on|off — value-aware kill-switch for authoring guards
                                                north config routing — allocation detail inside auto: provider order, pressure, reserves, envelopes
                                                north config learning — frozen known-best or learning bounded experimental assignment
  north providers [--json]                      provider readiness and the auto-route decision
  north learning compare <experiment-id> [--json]
                                                descriptive exact-task cohorts from immutable learning facts
                                                retains excluded attempts, retry lineage, propensities, and unknown measurements
                                                observed cohort summaries are descriptive only, never causal effects
  north account <sub>                           isolated provider subscription accounts
                                                add|login|status|list|usage|availability — homes under ~/.local/state/north/accounts
  north failover check|fire                     classify active rungs; compose/launch a provider-recovery lead
                                                fire --thread ID --brief PATH [--dry-run] — only fire may launch
  north spend status|init|override              API-billing budget: cap, reserved, settled, headroom
  north ccr prepare|retrieve                    default-off structured-output CCR canary

STORE — the fact corpus and its schema
  north schema                    vocabulary census: subjects/facts by kind + predicate metadata
  north predicate ls|show|define  inspect or extend executable predicate entities
  north validate                  full integrity check: engine rules + north work rules
  north audit                     corpus-health report
  north history <id>              a subject's full fact history from the log
  north json <view>               machine-readable projections (ready, show, …)
  north tools                     the curated MCP tool surface + the Beagle Store engine core
  north boot                      session orientation from the live coordination projection
  north import                    fold threads/ file edits into the log (idempotent, safe anytime)
  north export <out-dir>          regenerate threads/ from the log — never during concurrent work

  supported unregistered verbs pass through to the Beagle Store engine (ask, watch, …)

OPS — daemons, health, deployment
  north dashboard [--once]                      live fleet, health, board, and accounts snapshots
  north bridge <prompt>|dashboard|pending|accept|attach|msg|interrupt <execution-id>
                                                dashboard, launch, attach, or control a journaled local Codex session
                                                dashboard — render the Bridge operator cockpit (north dashboard remains an alias)
                                                pending [--consume <id>] — list or consume durable terminal lane completions
                                                accept — run the two-session reconnect/control/journal acceptance demo
                                                msg <id> <text> — queue input for the next turn on the same provider thread
                                                interrupt <id> — interrupt the active turn without terminating its session
  north run-share export <bridge-uuid> --out <new-directory>
                                                export a redacted encrypted Wire replay with a local read-only viewer
                                                creates private run.northshare and viewer.html files without overwriting
                                                prints one file URL whose fragment contains the decryption key
  north doctor                                  is everything healthy: fact server, daemons, rev skew, env, hooks
  north health                                  coordination rollup: lanes ran/died, stale concerns, zombies
  north hotspots                                where time goes and what fails, ranked from live telemetry
  north coord-ready                             cheap exact runtime identity for every active writer
  north coord-safety                            runtime identity + strict log-fence round trip
  north acp                                     serve the bounded local ACP endpoint over stdio
  north stream-sync                             cursor-based transcript log-shipping
  north stream-distill --project-root DIR --stream-thread ID [--lineage SHA256]
                                                claim one settled mirror and publish its Tier 1 distillation
  north panic                                   minimal recovery path; works with bb/Store/coordinator down
  north help [<topic>|--all]                    the card; a topic page; or the complete reference
