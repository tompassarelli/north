# Quaternius library

Location: `~/code/game-assets/quaternius/`. Inspect it before creating actor or scenery visuals or seeking downloads.

- `All in One - Quaternius[Patreon].zip`: animated characters, animals, monsters, medieval villages, props, nature and Universal Animation Libraries 1 and 2.
- `Universal Animation Library[Standard].zip`: Universal Animation Library 1.

Extraction and licensing:

- Extract only the chosen coherent subset of models, buffers, textures, animations and license notices into the project's assets.
- Keep the shared archives intact and outside game repositories and web releases.
- Prefer glTF/GLB where the engine supports it.
- Preserve pack names and archive member paths in the project's attribution record.
- Retain and check the selected packs' bundled terms, including Patreon-labelled content, against the all-in-one root `License.txt`'s CC0 1.0 Universal declaration.

Animation checks:

- Read the actual clip names and skeleton bindings before selecting animations.
- Prefer compatible native clips over retargeting.
