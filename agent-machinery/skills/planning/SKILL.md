# Engineering planning

1. Define outcome, scope, preserved behavior, consequential decisions and completion evidence.
2. Choose the shortest implementation path with an early falsifying check of its central risk.
3. Include migration, recovery, compatibility or rollout only for an affected boundary.
4. Use `prior-art` for consequential uncertainty and stop when further prose changes no action.

Read [plan outline](references/notes.md) when a durable decision needs a written plan.
