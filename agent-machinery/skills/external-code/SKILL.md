# External code

1. Identify the exact source revision and license before derivation, because rights attach to a specific revision and its covered scope.
2. Resolve missing, restrictive, copyleft or source-available rights before copying, because public visibility is not permission and attribution does not cure missing permission.
3. Preserve required copyright, license, attribution and notices, because most licenses make them a condition of use.
4. Record source, revision, license, reused scope and obligations, so a later reader can check compliance without re-researching.
5. When you adopt or test an outside source, add its entry to the repository's `docs/references.md`, when it has one, in the same commit, so the record cannot lag the code.

Read [rights and record format](references/notes.md) when distinguishing facts from expression.
