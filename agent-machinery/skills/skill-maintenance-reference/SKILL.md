# Skill maintenance: full notes

## Extract the stable decision

Strong or repeated feedback is evidence that a decision needs durable guidance,
not that every detail of the incident should become policy. Identify the
trigger, desired move, real scope, exceptions, and the previous failure.
Preserve explicit user intent; do not generalize an example into unrelated work.

## Choose the owning layer

Search the current source and catalog first. A universal boundary belongs in
the nearest applicable AGENTS policy. A coherent on-demand procedure belongs
in one skill. A deterministic refusal may belong in a hook, but emotional force
alone does not make a judgment mechanically enforceable.

Prefer correcting an existing owner to creating another rule. If two sources
disagree, fix the authority split instead of instructing models to reconcile it
forever.

## Distilled and full notes

The distilled guide is a complete routine operating surface, not a teaser
requiring every reference. Keep triggers and non-obvious decisions there.
The full notes preserve causal reasoning, examples, counterexamples, rejected
alternatives, and explicitly labeled conjectures for future re-distillation.

An adopted rule and an exploratory idea have different status. Separate them;
do not hide a binding safety condition in optional notes or promote a
brainstorm into a mandatory checklist. Split only when topics have different
read triggers. A short reference need not acquire a router.

## Validation

Check a positive case and a nearby case that should not activate the rule.
Would the instruction select the right source, action, and stopping condition
without expanding scope? Use metadata/link checks for structure and an existing
behavior fixture when enforcement changes. Text matching cannot prove judgment.

If behavioral evaluation is justified and authorized, give the evaluator the
realistic request and raw inputs without leaking the desired answer.
Verify landed source and consumer projection before claiming active policy.

A useful record names the trigger, scoped rule, compliant move, exceptions,
observed result, and any unresolved evidence. It need not become a new artifact.
