## Owner ratchet

Search the current package or repository catalog and source before choosing an
owner. An always-loaded instruction is appropriate only where its boundary must
govern every matching action. A skill is appropriate for one coherent optional
workflow. A hook is appropriate only for deterministic enforcement, not as a
reaction to the force of the feedback.
