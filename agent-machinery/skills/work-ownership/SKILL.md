# Work ownership

1. Use `work-ownership-v1` for work transitions.
2. Keep the current owner until an offer is accepted; assign the recipient and make the previous owner accountable parent on acceptance.
3. Require acknowledgment for direct transfer while preserving the accountable parent.
4. Clear refused offers and send escalated decisions to the parent without changing owner or goal.
5. Return results to the immediate parent within the accepted authority.
6. Assign ownership only to humans, listener agents or concrete agent runs.
