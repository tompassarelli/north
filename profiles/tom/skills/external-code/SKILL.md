# External code

Read `north:profiles/tom/docs/external-code.md` before leveraging the source.

1. Inspect the source's license terms before building on it.
2. Apply the documented license decision: preserve required attribution and
   notices for permissive code; flag copyleft or restrictive terms before
   deriving or copying; for an unspecified license, preserve the upstream
   identity and record the documented local default.
3. Treat `~/code/resources/` as read-only context. Separate ideas from copied
   expression when deciding what the license permits.

Use `importing-skills` for third-party skill installation; it owns that
specialized payload and provider-registration procedure.
